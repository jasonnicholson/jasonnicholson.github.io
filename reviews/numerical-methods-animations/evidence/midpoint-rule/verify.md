# Verification: midpoint-rule
## A1 — confirmed with correction
- What I checked: I computed the exact integral of f(x)=e^{-x} sin(8x^{2/3})+1 on [0,2] to 40 digits with mpmath, using the substitution x=t^3 to remove the endpoint singularity. Two quadratures agreed: I = 2.0162797196170963... I then computed the composite midpoint M_n for every n in the script's n_seq and for n=2^k up to 32768, and looked at E(n)/E(2n) and the observed order log2 of that ratio.
- Evidence: verify/conv.py.
  - My M_120 = 2.016771455 matches the committed final frame (frame_025.png shows "Approximation = 2.016771").
  - Doubling pairs inside the animation's n range give E(n)/E(2n) = 1.40 (5→10), 2.08 (6→12), 2.44 (7→14), 2.64 (8→16), 2.86 (10→20), 2.96 (12→24), 3.02 (14→28), 3.05 (16→32), 3.09 (20→40), 3.11 (24→48), 3.12 (28→56) and 3.13 (32→64). For n≤4 the error changes sign, so the ratios there mean nothing.
  - Asymptotically the ratio tends to 3.173 at n=32768, with observed order 1.666. That matches the theory: x^{2/3} has an unbounded first derivative at x=0, so the error is O(Δx^{5/3}) and the ratio tends to 2^{5/3}=3.1748, not 4.
- Severity: Misleading is fair. Line 37 is narrowly true because it says "for smooth f", but the page's only integrand is not smooth at x=0. That fact is never mentioned, and line 41 says this same function "converges as n grows" in the animation. A reader would expect error ratios near 4 for the animated function, but the ratios are about 3.1 at best and as low as about 1.4 to 2.6 at the frames' smaller n. It is not an Error, because the stated theorem is correct for smooth f.
- Correction to the allegation (if any): Line 37 is in "Derivation Notes", not directly in the animation section, and it is qualified with "for smooth f". The substance still holds. On "substantially smaller than 4": the asymptotic ratio is 2^{5/3}≈3.17 (order 5/3 instead of 2), which is clearly lower but not drastically.
