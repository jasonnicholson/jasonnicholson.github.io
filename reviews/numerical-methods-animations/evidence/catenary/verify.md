# Verification: catenary
## A1 — confirmed with correction
- What I checked: the sign of catenary minus parabola, where the two curves visibly separate, and where each curve leaves the plotted window (xlims ±4, ylims 0–12), across the 25 c values in catenaryaa.jl. I also looked at frames 1 (c=0.5) and 25 (c=4).
- Evidence:
  - Math: c·cosh(x/c) − (x²/(2c) + c) = x⁴/(24c³) + x⁶/(720c⁵) + … Every term is positive, so the gap is > 0 for every x ≠ 0. The catenary lies on or above the parabola and never below it. It rises more steeply. In the plot's y-up coordinates it does not "hang deeper"; both curves share the lowest point (0, c).
  - verify/check.py: on the script's grid, min(cat − par) ≥ 0 for every c, and is zero only at x = 0. For c = 0.5 the gap reaches 0.1 y-units (a few pixels) at |x| = 0.73. The catenary leaves y = 12 at |x| = 1.94 and the parabola at |x| = 3.39. The gap at x = 4 is 729 units, far off-screen. So at small c the separation is visible near |x| ≈ 0.7–2, well inside the window and not at the endpoints.
  - Window exit thresholds (mpmath): the parabola leaves the window before x = ±4 only when c < 0.7085 (frames 1–2: c = 0.5, 0.646). The catenary leaves before x = ±4 when c < 1.4146 (frames 1–7).
  - Frame 1 (c = 0.5): the blue catenary is the narrow inner U and the red dashed parabola the wider outer U. They split at about |x| ≈ 0.7 and leave the top of the plot at about x ≈ ±1.9 and ±3.4. Frame 25 (c = 4): the curves coincide except near x = ±4, where the catenary is slightly above. So "diverges at the endpoints" actually describes large c, not small c.
- Severity: Misleading is fair, arguably on the strong side of Misleading. "Hangs deeper" is wrong in the plot's coordinates: the catenary is always above. It is defensible only physically (small c means more sag for a fixed span), which this fixed-vertex plot does not show. The "endpoints" claim is wrong for the small-c frames.
- Correction to the allegation: "both leaving the plotted window before x = ±4 for small c" holds only for c < 0.7085 (the first 2 of 25 frames). For c up to about 1.41 (frames 1–7), only the catenary leaves before ±4. The core points stand: the catenary is never below the parabola, and at small c the curves separate well inside the window.
