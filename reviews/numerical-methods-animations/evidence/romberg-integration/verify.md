# Verification: romberg-integration
## A1 — confirmed with correction
- What I checked: Built the Romberg table independently at 50 digits (mpmath) for f(x)=1+e^{-x} sin(8 x^{2/3}) on [0,2], with the same row sequence as rombergaa.jl (n = 1,2,4,...,128 panels, m = 2..129), extended to 12 rows to see the asymptotic rate. Exact integral computed two independent ways (mpmath.quad with breakpoints near 0, and after the substitution x=t^3, which removes the singularity) — both give I = 2.01627971961709632788727. Control: the same procedure on the smooth analogue 1+e^{-x} sin(8x). Checked the last committed frame (committed/rombergaa/frame_009.png) — it shows R[k,k] = 2.016007 and row-8 entries matching my table (2.015080, 2.015945, 2.015994, ...).
- Evidence: verify/romb.py. Diagonal error |R[k,k]-I| for k=4..12: 4.6e-2, 8.1e-3, 2.76e-3, 8.69e-4, 2.73e-4, 8.59e-5, 2.70e-5, 8.51e-6, 2.68e-6; successive ratios 3.18, 3.18, 3.18, 3.18, 3.18 -> 2^{5/3} = 3.175, i.e. O(h^{5/3}). Raw trapezoid errors decay at the same ratio (~3.17); the diagonal is only a constant ~4.4x better than T at the same level. Final displayed entry R[8,8] = 2.01600675 vs I = 2.01627972: error 2.73e-4 (wrong in the 4th decimal; only the first 3-4 digits correct, and the 6-decimal value on the GIF looks converged but is not). Smooth control 1+e^{-x}sin(8x): diagonal error ratios 40, 182, 822, 4051 and R[8,8] error 2.2e-12 — eight orders of magnitude better at the same cost. Cause: x^{2/3} makes f' unbounded at x=0, so the trapezoid error expansion has non-even powers (h^{5/3}, ...) that Richardson with factors 4^{j-1} does not eliminate. Within row 8 the diagonal is still the best entry (errors monotonically decrease from 1.2e-3 to 2.73e-4), so line 33's "best estimate at that stage" is true here.
- Severity: Misleading is fair. Line 21 is narrowly true ("for smooth integrands"), but the page never says that its only example is not smooth at 0, and the animation shows a stable-looking 6-digit diagonal that is in fact wrong at the 4th decimal and converging at the trapezoid's own algebraic rate. A reader would come away believing they saw Romberg's rapid convergence.
- Correction to the allegation (if any): The "converging quickly" wording is only on line 21 (the general statement qualified by "smooth"). Line 26 only says "Romberg refinement process" and the alt text at 37 says only that the "diagonal estimates converge", which is literally true (they converge, slowly). So lines 26 and 37 contribute by framing, not by an explicit false claim. Quantitatively: the diagonal rate is O(h^{5/3}) (ratio 3.175 per halving), the same order as plain trapezoid, not merely "no faster than a low algebraic rate".
