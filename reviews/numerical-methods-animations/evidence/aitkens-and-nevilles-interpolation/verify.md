# Verification: aitkens-and-nevilles-interpolation

## A1 — confirmed
- What I checked: Built both tableaux exactly (sympy) for the page's data (cos at 0, pi/4, pi/2, 3pi/4, pi), query x = 1/3. Neville: P_{i,j} combines P_{i+1,j} and P_{i,j-1} (consecutive node sets {i..j}). Aitken: A_{k,j} = [(x-x_{k-1})A_{k-1,j} - (x-x_j)A_{k-1,k-1}]/(x_j-x_{k-1}), i.e. the interpolant on {x_0..x_{k-1}, x_j} -- it always combines with the fixed "diagonal" entry, not with a neighbouring entry.
- Evidence: verify/check.py. Level-2 entries: Neville [0.92629, 1.11411, 1.95456] (nodes {0,1,2},{1,2,3},{2,3,4}); Aitken [0.92629, 0.90942, 0.89256] (nodes {0,1,2},{0,1,3},{0,1,4}). Each verified against direct Lagrange interpolation on those node sets. Final values agree (0.952857116...) as uniqueness requires.
- Severity: Error is fair. "Aitken's process is the same recursion" is false: different formula, different intermediate polynomials (non-contiguous node sets), only the final interpolant coincides. "Combining neighboring approximants" actually describes Neville's scheme, not Aitken's. Both are "repeated linear interpolation", which is the only true part.
- Correction to the allegation: none.

## A2 — confirmed with correction
- What I checked: Exact symbolic interpolants of the first 4 and all 5 nodes; max error on the script's plot grid for each degree; committed frames 4 and 5.
- Evidence: verify/check.py: P4 - P3 = 0 exactly; x^4 coefficient of P4 = 0; P3(pi) = -1 = cos(pi). Reason: cos(pi - x) = -cos(x), so the data are odd about pi/2, the 5-node interpolant is odd about pi/2 and has degree <= 3, hence equals the unique cubic through the first 4 nodes. Max |err| on plot grid: deg3 0.0085187, deg4 0.0085187 (identical). Frames 4 and 5 (committed/nevilleaa/sheet.png) show the same red curve; only the title, legend label and the extra node dot at pi differ (the cubic already passes through (pi,-1)).
- Severity: Misleading is fair -- the "degree 4" frame is P_{0,4} (degree <= 4) so the label is narrowly defensible, but readers are told each node refines the polynomial and degree 4 is the culmination, while the last step changes nothing.
- Correction to the allegation: the misleading claims are mainly lines 25 ("successively higher-degree interpolants") and 31 ("Adding each node refines the polynomial"; "By degree 4 ... closely matches", already true at degree 3). Lines 29, 35 and the frame title only say "degree 0 through 4"/"degree 4", which are labels for P_{0,4} and only misleading by implication -- a weaker part of the allegation. Additional observation (not alleged): "Adding each node refines" also fails globally at degree 2 -- max error on the plot range rises from 0.899 (deg 1) to 1.887 (deg 2).
