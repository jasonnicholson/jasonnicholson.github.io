# Numerical Methods section

The pages under `pages/numerical-methods/` were built in 2026 from John H. Mathews' Numerical Analysis site, which I recovered from the Internet Archive (see [mathews-archive.md](mathews-archive.md)). The work finished on 2026-11-28.

## Regenerating an animation

Each animated case has its own Julia script next to its GIF in the page folder. The script writes the GIF next to itself (through `@__DIR__`), so running it overwrites the committed GIF, whatever directory you run it from. Run it in the section's Julia project:

```bash
julia --project=pages/numerical-methods pages/numerical-methods/<page>/<script>.jl
```

To try a change without touching the committed GIF, copy the script to a scratch folder and run the copy there; its GIF lands next to the copy. Compare the result with `cmp`.

The GIFs are stored with Git LFS.

## Julia environment

`pages/numerical-methods/Project.toml` and `pages/numerical-methods/Manifest.toml` are the section's own environment. The manifest is the lock file.

- **Direct dependencies:** Plots 1.41.2 and SpecialFunctions 2.7.2, plus the standard libraries LinearAlgebra, Printf and Random. Julia 1.12.2.
- **Where the versions came from:** the manifest was made on 2026-11-28 from the global environment (`~/.julia/environments/v1.12`) that built every GIF. Gridap, GridapGmsh and ForwardDiff were removed, and nothing was re-resolved. All 183 packages have the same versions as there. `bisectionaa.gif`, `rungekuttaaa.gif` and `frobeniusbb.gif` (a SpecialFunctions script) regenerated byte for byte under it.
- **Setting it up on a new machine:**

  ```bash
  julia --project=pages/numerical-methods -e 'using Pkg; Pkg.instantiate()'
  ```

- **Updating:** `Pkg.update()` in this project can move Plots or its dependencies. Regenerated GIFs may then differ in bytes, or slightly in look, from the committed ones. Commit the new manifest together with any GIFs you regenerate.

### Why this is a separate project

Julia has no dependency groups like Python's (PEP 735, `uv`'s `[dependency-groups]`). There are two near equivalents:

- **A separate environment per folder.** This is the one used here.
- **Workspaces** (Julia 1.12). A root `Project.toml` lists subprojects in `[workspace]`, and they share one root `Manifest.toml`.

The root `Project.toml` and `Manifest.toml` belong to Quarto's Julia engine (`engines: ['julia']` in `_quarto.yml`: Quarto, QuartoNotebookRunner, Julia 1.12.1). A workspace would resolve Plots together with them in that one manifest. It could move the versions Quarto renders with, so the section keeps its own environment instead.

## Decisions it was finished with

- **Word-count exceptions.** The overview standard is 150–400 words of prose in each page's Description. Six *check* pages are granted an exception and stay over 400, because their Descriptions had already been reviewed before the overview pass and were only added to, not trimmed:

  | Page | Words |
  |---|---|
  | Damped Newton with Acceleration (Madsen-Reid Method) | 1167 |
  | Broyden's Method | 539 |
  | Brent's Method | 500 |
  | Aitken's Method and Steffensen's Acceleration | 464 |
  | Nonlinear Systems | 441 |
  | Graeffe's Method | 417 |

- **Hypotheses in the order results.** The Runge-Kutta, Runge-Kutta-Fehlberg and Taylor Series pages state their order results with $f$ smooth near the solution, not with Mathews' wording, which puts the condition on the solution $y$ alone. The Adams-Bashforth-Moulton page keeps Mathews' $y \in C^5$, which is enough for a multistep method when $f$ is Lipschitz.
- **Small points left as they are:**
  - The Trapezoidal Rule page says "Romberg Integration repeats that step on successive trapezoidal sums". That is loose, since Romberg's later columns use weights $4^k$. Only one reviewer flagged it, and that reviewer was checking a test copy with planted errors. The two reviewers of the real page accepted it.
  - The Madsen-Reid page's title says "Damped Newton", which describes only its step-halving branch.
