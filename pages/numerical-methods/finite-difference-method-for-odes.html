Finite Difference Method for ODE’s

← Numerical Methods

Source inspiration: (Mathew 2000-2019).

Description

A second-order boundary value problem asks for a function \(x(t)\) on an interval \([a, b]\) that satisfies a differential equation inside the interval and prescribed values at both ends. For the linear equation

\[ x'' = p(t)\,x' + q(t)\,x + r(t), \qquad x(a) = \alpha, \quad x(b) = \beta, \]

the finite difference method divides \([a, b]\) into \(n\) equal subintervals of width \(h = (b - a)/n\), with mesh points \(t_j = a + jh\), and looks for numbers \(x_j \approx x(t_j)\). At every interior mesh point it replaces \(x'\) and \(x''\) by central difference quotients, which turns the differential equation into one linear equation linking \(x_{j-1}\), \(x_j\) and \(x_{j+1}\):

\[ \Bigl(-\frac{h}{2}p_j - 1\Bigr)x_{j-1} + \bigl(2 + h^2 q_j\bigr)x_j + \Bigl(\frac{h}{2}p_j - 1\Bigr)x_{j+1} = -h^2 r_j, \qquad j = 1, 2, \ldots, n-1, \]

where \(p_j = p(t_j)\), \(q_j = q(t_j)\), \(r_j = r(t_j)\), \(x_0 = \alpha\) and \(x_n = \beta\). These \(n - 1\) equations form a tridiagonal linear system, which tridiagonal elimination solves in \(O(n)\) operations, and the solution values together with the two boundary values give the approximate solution curve.

Both difference quotients are accurate to \(O(h^2)\). Under the conditions stated below, and for a smooth solution, the error of the method is then \(O(h^2)\), so halving \(h\) cuts it by about a factor of four, and two runs with \(h\) and \(h/2\) can be combined by Richardson extrapolation into a much more accurate answer. Mathews’ examples do exactly this for one equation on \([1, 6]\) with \(25\) and \(50\) subintervals; every number below has been recomputed (the example tables in 40-digit arithmetic), and the computed solutions are compared with the exact solution.

Boundary Value Problems

The boundary value problem \(x'' = f(t, x, x')\), \(x(a) = \alpha\), \(x(b) = \beta\) need not have a solution, and when it has one it need not be unique. The following theorem gives a sufficient condition. In it, \(y\) stands for the third argument of \(f\), the slot where \(x'(t)\) goes, so that the partial derivatives \(f_x\) and \(f_y\) can be written down.

TipTheorem — Boundary value problem

Assume that \(f(t, x, y)\) is continuous on the region \(R = \{(t, x, y) : a \le t \le b,\ -\infty < x < \infty,\ -\infty < y < \infty\}\) and that \(f_x\) and \(f_y\) are continuous on \(R\). If there is a constant \(M > 0\) for which

\[ f_x(t, x, y) > 0 \quad\text{and}\quad |f_y(t, x, y)| \le M \qquad \text{for all } (t, x, y) \in R, \]

then the boundary value problem

\[ x'' = f(t, x, x'), \qquad x(a) = \alpha, \quad x(b) = \beta \]

has a unique solution \(x = x(t)\) for \(a \le t \le b\).

For a linear equation, \(f(t, x, y) = p(t)\,y + q(t)\,x + r(t)\), so \(f_x = q(t)\) and \(f_y = p(t)\), and the theorem becomes:

TipCorollary — Linear boundary value problem

Assume that \(p\), \(q\) and \(r\) are continuous on \([a, b]\) and that

\[ q(t) > 0 \qquad \text{for all } t \in [a, b]. \]

Then the linear boundary value problem

\[ x'' = p(t)\,x'(t) + q(t)\,x(t) + r(t), \qquad x(a) = \alpha, \quad x(b) = \beta \tag{1} \]

has a unique solution \(x = x(t)\) over \(a \le t \le b\). (A bound \(|p(t)| \le M\) is automatic here, with \(M = \max_{a \le t \le b} |p(t)|\), because \(p\) is continuous on a closed interval.)

WarningThe condition \(q(t) > 0\) is sufficient, not necessary

The equation \(x'' = -x\) has \(q(t) = -1 < 0\), and its general solution is \(x(t) = c_1 \cos t + c_2 \sin t\). With the boundary conditions \(x(0) = \alpha\) and \(x(\pi) = \beta\), the first condition gives \(c_1 = \alpha\) and the second gives \(x(\pi) = -c_1 = -\alpha\), so the problem can be solved only when \(\beta = -\alpha\), and then \(c_2\) is arbitrary and there are infinitely many solutions. (Mathews’ footnote states the condition as \(\alpha = \beta\); the general solution gives \(\beta = -\alpha\).) This counterexample is why the theory is phrased with \(q(t) > 0\). But the condition is only sufficient: many problems with \(q(t) < 0\) somewhere, including the one solved on this page, still have exactly one solution, and they can be solved by finite differences or by the shooting method with some care.

The Finite-Difference Method

Derivation

Consider the linear equation (1) over \([a, b]\) with \(x(a) = \alpha\) and \(x(b) = \beta\). Form a partition of \([a, b]\) using the points \(a = t_0 < t_1 < \cdots < t_n = b\), where

\[ h = \frac{b - a}{n} \qquad\text{and}\qquad t_j = a + jh \quad\text{for } j = 0, 1, \ldots, n. \]

The central difference formulas approximate the derivatives at an interior point \(t_j\):

\[ x'(t_j) = \frac{x(t_{j+1}) - x(t_{j-1})}{2h} + O(h^2), \tag{2} \]

\[ x''(t_j) = \frac{x(t_{j+1}) - 2x(t_j) + x(t_{j-1})}{h^2} + O(h^2). \tag{3} \]

For a solution with continuous fourth derivative the two error terms are \(-\tfrac{h^2}{6}x'''(c_1)\) and \(-\tfrac{h^2}{12}x^{(4)}(c_2)\) for some \(c_1, c_2\) in \((t_{j-1}, t_{j+1})\); Taylor expansion of the quotients gives \(x' + \tfrac{h^2}{6}x''' + \cdots\) and \(x'' + \tfrac{h^2}{12}x^{(4)} + \cdots\).

Write \(x_j\) for the approximation to \(x(t_j)\), drop the two \(O(h^2)\) terms, and use the notation \(p_j = p(t_j)\), \(q_j = q(t_j)\) and \(r_j = r(t_j)\). Equation (1) at \(t = t_j\) becomes the difference equation

\[ \frac{x_{j+1} - 2x_j + x_{j-1}}{h^2} = p_j\,\frac{x_{j+1} - x_{j-1}}{2h} + q_j x_j + r_j. \tag{4} \]

Multiply each side by \(h^2\) and collect the terms involving \(x_{j-1}\), \(x_j\) and \(x_{j+1}\):

ImportantThe finite difference equations

\[ \Bigl(-\frac{h}{2}p_j - 1\Bigr)x_{j-1} + \bigl(2 + h^2 q_j\bigr)x_j + \Bigl(\frac{h}{2}p_j - 1\Bigr)x_{j+1} = -h^2 r_j \tag{5} \]

for \(j = 1, 2, \ldots, n - 1\), where \(x_0 = \alpha\) and \(x_n = \beta\).

(Mathews’ module prints the left boundary value as \(x_0 = \beta\); it is \(x_0 = x(a) = \alpha\).)

The tridiagonal system

Equation (5) for \(j = 1\) contains the known value \(x_0 = \alpha\), and for \(j = n - 1\) the known value \(x_n = \beta\); moving these to the right-hand side leaves \(n - 1\) equations in the \(n - 1\) unknowns \(x_1, \ldots, x_{n-1}\). Write

\[ d_j = 2 + h^2 q_j, \qquad a_j = -\frac{h}{2}p_j - 1, \qquad c_j = \frac{h}{2}p_j - 1, \qquad e_j = -h^2 r_j. \]

Then the system is

\[ \begin{pmatrix} d_1 & c_1 & & & \\ a_2 & d_2 & c_2 & & \\ & \ddots & \ddots & \ddots & \\ & & a_{n-2} & d_{n-2} & c_{n-2} \\ & & & a_{n-1} & d_{n-1} \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_{n-2} \\ x_{n-1} \end{pmatrix} = \begin{pmatrix} e_1 - a_1\alpha \\ e_2 \\ \vdots \\ e_{n-2} \\ e_{n-1} - c_{n-1}\beta \end{pmatrix}, \tag{6} \]

which has the familiar tridiagonal form and is solved by elimination in \(O(n)\) operations.

TipWhen the system has a unique solution (general result)

Suppose \(q(t_j) > 0\) at every interior mesh point and \(h\,|p(t_j)| \le 2\) there (for instance \(h \le 2/M\) with \(M = \max_{a \le t \le b}|p(t)|\)). Then \(a_j \le 0\) and \(c_j \le 0\), so \(|a_j| + |c_j| = \bigl(1 + \tfrac{h}{2}p_j\bigr) + \bigl(1 - \tfrac{h}{2}p_j\bigr) = 2 < 2 + h^2 q_j = d_j\). Every row of (6) is strictly diagonally dominant, so the matrix is nonsingular and the tridiagonal elimination needs no pivoting.

When \(q\) is negative, as in the example below, the matrix is not diagonally dominant and nonsingularity has to be checked another way; it does not follow from this result.

The finite difference solution also converges to \(x(t)\) as \(h \to 0\): under the conditions of the corollary, with \(h \le 2/M\), and for a solution with continuous fourth derivative, the error at the mesh points is \(O(h^2)\). This is a standard general result. The example below does not satisfy these conditions, but it shows the factor of four per halving of \(h\) numerically all the same.

Algorithm

To approximate the solution of \(x'' = p(t)x'(t) + q(t)x(t) + r(t)\) with \(x(a) = \alpha\) and \(x(b) = \beta\) over \([a, b]\) by the finite difference method of order \(O(h^2)\), Mathews’ program uses the mesh \(a = t_1 < t_2 < \cdots < t_{n+1} = b\) (numbered from \(1\), so it has \(n + 1\) points for \(n\) subintervals) and returns the solution points \(\{(t_j, x_j)\}_{j=1}^{n+1}\). Its three steps are:

  1. Construct the tridiagonal matrix and the right-hand-side vector of (6).
  2. Solve the system in step 1 for the ordinates strictly inside the interval.
  3. Join the mesh points and the solution vector from step 2 into points, and put the boundary points \((a, \alpha)\) and \((b, \beta)\) at the two ends.

Worked Examples

All six of Mathews’ examples use the same boundary value problem,

\[ x'' + \frac{1}{t}\,x' + \Bigl(1 - \frac{1}{4t^2}\Bigr)x = \sqrt{t}\,\cos t, \qquad x(1) = 1, \quad x(6) = -0.5, \tag{7} \]

over \([1, 6]\). In the form (1) it has

\[ p(t) = -\frac{1}{t}, \qquad q(t) = \frac{1}{4t^2} - 1, \qquad r(t) = \sqrt{t}\,\cos t. \]

Here \(q(t)\) decreases from \(q(1) = -0.75\) to \(q(6) = -0.993056\), so it is negative on the whole interval and the corollary does not apply. The problem nevertheless has exactly one solution, which can be written down.

The exact solution

The homogeneous equation \(x'' + \tfrac{1}{t}x' + \bigl(1 - \tfrac{1}{4t^2}\bigr)x = 0\) is Bessel’s equation of order \(\tfrac12\). The substitution \(x = u/\sqrt{t}\) turns (7) into

\[ u'' + u = t\cos t, \]

whose general solution is \(u = c_1\cos t + c_2\sin t + \tfrac14 t\cos t + \tfrac14 t^2\sin t\). Hence

\[ x(t) = \frac{c_1\cos t + c_2\sin t}{\sqrt{t}} + \frac14\sqrt{t}\,\cos t + \frac14\,t^{3/2}\sin t. \tag{8} \]

The boundary conditions give two linear equations for \(c_1\) and \(c_2\), whose determinant is \(\cos 1\,\sin 6 - \sin 1\,\cos 6 = \sin 5 = -0.958924 \neq 0\), so there is exactly one solution:

\[ c_1 = 0.0588713451552886, \qquad c_2 = 0.740071095780206, \]

the same constants that Mathews uses in Example 6. The same determinant shows that the homogeneous problem with \(x(1) = x(6) = 0\) has only the zero solution. Formula (8) satisfies (7) and both boundary conditions to 40-digit precision, and an independent numerical solution of (7) with SciPy’s solve_bvp agrees with it to within \(9 \times 10^{-16}\) on \([1, 6]\). Its minimum on \([1, 6]\) is about \(-2.9057\), near \(t = 4.78\).

Example 1 — \(25\) subintervals, step by step

Solve (7) over \([1, 6]\) with the finite difference method and \(n = 25\) subintervals (\(26\) points).

Step 1: The mesh. With \(h = (6 - 1)/25 = 0.2\),

\[ t_j = 1 + 0.2j, \qquad j = 0, 1, \ldots, 25, \]

and the unknowns are \(x_1, \ldots, x_{24}\) at \(t = 1.2, 1.4, \ldots, 5.8\).

Step 2: The coefficient functions at the mesh points. At \(t_1 = 1.2\),

\[ p_1 = -\frac{1}{1.2} = -0.833333, \qquad q_1 = \frac{1}{4(1.44)} - 1 = -0.826389, \qquad r_1 = \sqrt{1.2}\,\cos 1.2 = 0.396943. \]

Step 3: The first row of (6). With \(h/2 = 0.1\) and \(h^2 = 0.04\),

\[ d_1 = 2 + 0.04\,q_1 = 1.966944, \qquad c_1 = 0.1\,p_1 - 1 = -1.083333, \]

\[ e_1 - a_1\alpha = -0.04\,r_1 + (1 + 0.1\,p_1)(1) = -0.015878 + 0.916667 = 0.900789. \]

The second row, at \(t_2 = 1.4\), is the first full one: \(a_2 = -0.928571\), \(d_2 = 1.965102\), \(c_2 = -1.071429\) and right-hand side \(e_2 = -0.04\,r_2 = -0.008044\).

Step 4: The last row, at \(t_{24} = 5.8\), where \(p_{24} = -0.172414\), \(q_{24} = -0.992568\) and \(r_{24} = 2.132613\):

\[ a_{24} = -0.1\,p_{24} - 1 = -0.982759, \qquad d_{24} = 2 + 0.04\,q_{24} = 1.960297, \]

\[ e_{24} - c_{24}\beta = -0.04\,r_{24} + (1 - 0.1\,p_{24})(-0.5) = -0.085305 - 0.508621 = -0.593925. \]

These are the first and last entries of the four vectors Mathews prints (sub-diagonal, diagonal, super-diagonal, right-hand side), and all four agree with the recomputation to the six figures he shows.

Step 5: Solve the \(24 \times 24\) tridiagonal system. Because \(q < 0\), the diagonal entries run from \(d_1 = 1.966944\) down to \(d_{24} = 1.960297\), all below \(2\), while \(|a_j| + |c_j| = 2\) in rows \(2\) to \(23\); so the matrix is not diagonally dominant and the general result above does not apply. It is nonsingular all the same: its determinant is \(-4.903642\) and its condition number (2-norm) is about \(225\).

Step 6: Put the boundary points \((1, 1)\) and \((6, -0.5)\) at the ends of the list of points \((t_j, x_j)\). The finite difference solution, compared with the exact solution (8), is:

Example 4 — how much do the two solutions differ?

The two solutions cannot be subtracted directly: \(X_1\) has \(26\) points and \(X_2\) has \(51\). The mesh of \(X_1\) is every other point of the mesh of \(X_2\), so Mathews takes points \(1, 3, 5, \ldots, 51\) of \(X_2\) (numbering from \(1\)), which lie at \(t = 1.0, 1.2, \ldots, 6.0\), and forms the difference \(X_2 - X_1\) there. It appears in the table under Example 5. The difference is negative from \(t = 1.2\) to \(t = 3.4\), positive from \(t = 3.6\) to \(t = 5.8\), and largest in size at \(t = 4.8\), where \(X_2 - X_1 = 0.01100\).

Is that small or large? Since the method is of order \(O(h^2)\), the error of \(X_2\) should be about a quarter of the error of \(X_1\), so \(X_2 - X_1 \approx -\tfrac34(X_1 - x)\), and the difference itself estimates the error: \(X_1 - x \approx -\tfrac43(X_2 - X_1)\), which at \(t = 4.8\) is \(-\tfrac43(0.01100) = -0.01467\), close to the actual error \(-0.01464\). The improvement scheme of the next example removes most of it.

Example 5 — Richardson extrapolation

Use Richardson extrapolation and the results of Examples 2 and 3 to construct a more accurate solution at the \(26\) points of the \(25\)-subinterval mesh.

If the error of the method behaves like \(C h^2\) at a fixed point \(t\), then \(X_1 \approx x + Ch^2\) and \(X_2 \approx x + C h^2/4\). Eliminating \(C\) gives the extrapolated values

\[ X_3 = \frac{4X_2 - X_1}{3} = X_2 + \frac{X_2 - X_1}{3}. \tag{9} \]

(The output of this example is missing from Mathews’ archive; formula (9) is the one he uses in Example 6.) At \(t = 4.8\), for instance, \(X_3 = (4(-2.908846) - (-2.919846))/3 = -2.905179\), compared with the exact value \(-2.905208\).

The largest errors at these \(26\) points, all at \(t = 4.8\), are

\[ \max|X_1 - x| = 0.0146383, \qquad \max|X_2 - x| = 0.00363805, \qquad \max|X_3 - x| = 0.0000286914, \]

as Mathews reports. (Over all \(51\) points of the finer mesh, the largest error of \(X_2\) is slightly larger, \(0.0036531\) at \(t = 4.9\).) Their ratio is

\[ \frac{\max|X_2 - x|}{\max|X_1 - x|} = 0.24853 \approx \frac14, \]

and at each of the \(24\) interior common points the ratio \((X_2 - x)/(X_1 - x)\) lies between \(0.2448\) (at \(t = 3.4\)) and \(0.2501\) (at \(t = 3.6\)), the two points on either side of the sign change of the error. Halving \(h\) divides the error by about four, as a method of order \(O(h^2)\) should. Extrapolation works: the largest error of \(X_3\) is about \(510\) times smaller than that of \(X_1\) and about \(127\) times smaller than that of \(X_2\), although \(X_3\) uses no mesh finer than \(X_2\).
