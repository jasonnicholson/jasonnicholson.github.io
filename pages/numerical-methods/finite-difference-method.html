Finite Difference Method

← Numerical Methods

Source inspiration: (Mathew 2000-2019).

Description

This page covers the finite difference method for a hyperbolic partial differential equation, the one-dimensional wave equation, as Mathews’ module “Finite Difference Method for Hyperbolic Equations” does. The problem is to find the displacement \(u(x, t)\) of a vibrating string with fixed ends, \(u_{tt} = c^2 u_{xx}\) for \(0 < x < a\) and \(0 < t < b\), given its initial position \(u(x, 0) = f(x)\) and initial velocity \(u_t(x, 0) = g(x)\).

The method covers the rectangle \(0 \le x \le a\), \(0 \le t \le b\) with a grid of spacing \(h\) in \(x\) and \(k\) in \(t\), replaces both second derivatives by central differences, and solves the resulting difference equation for the newest time level. With \(u_{i,j} \approx u(x_i, t_j)\) and the ratio \(r = ck/h\), each new row of the grid comes from the two rows before it:

\[ u_{i,j+1} = (2 - 2r^2)\,u_{i,j} + r^2\,(u_{i+1,j} + u_{i-1,j}) - u_{i,j-1}. \]

The first row is \(f\), and a second row is built from \(f\) and \(g\) with a Taylor expansion. This is an explicit method: the rows are computed one after another, with no system of equations to solve. As a general result, it is stable when \(r \le 1\); for \(r > 1\) the shortest wavelengths that a fine enough grid can carry grow geometrically. When \(r = 1\) and the second row is exact, every value it computes is exact. Mathews’ three examples show both sides: Examples 1 and 2 use \(r = 1\) and reproduce the exact solution to rounding error, and Example 3 takes \(r = 1.02\) and is unstable.

The Wave Equation

NoteDefinition — The wave equation problem

Find \(u(x, t)\) satisfying

\[ u_{tt}(x, t) = c^2\, u_{xx}(x, t) \qquad \text{for } 0 < x < a \text{ and } 0 < t < b, \tag{1} \]

with the boundary and initial conditions

\[ \begin{aligned} u(0, t) &= 0 \quad \text{and} \quad u(a, t) = 0 && \text{for } 0 \le t \le b, \\ u(x, 0) &= f(x) && \text{for } 0 \le x \le a, \\ u_t(x, 0) &= g(x) && \text{for } 0 < x < a. \end{aligned} \tag{2} \]

The wave equation models the displacement \(u\) of an elastic string held fixed at \(x = 0\) and \(x = a\); \(c\) is the speed at which waves travel along it. Analytic solutions can be found with Fourier series or with d’Alembert’s formula below, but the problem serves as the prototype of a hyperbolic equation, and the same difference method applies where no formula is available.

Derivation of the Difference Equation

Partition the rectangle \(R = \{(x, t) : 0 \le x \le a,\ 0 \le t \le b\}\) into \(n - 1\) by \(m - 1\) rectangles with sides \(h = a/(n - 1)\) and \(k = b/(m - 1)\). Following Mathews, the grid points are numbered from \(1\):

\[ x_i = (i - 1)h, \quad i = 1, \ldots, n, \qquad t_j = (j - 1)k, \quad j = 1, \ldots, m, \]

and \(u_{i,j}\) denotes the approximation to \(u(x_i, t_j)\). The bottom row \(j = 1\) is the known initial position, \(u_{i,1} = f(x_i)\), and the end columns are the fixed ends, \(u_{1,j} = u_{n,j} = 0\).

The central-difference formulas for the two second derivatives are

\[ u_{tt}(x, t) = \frac{u(x, t + k) - 2u(x, t) + u(x, t - k)}{k^2} + O(k^2), \tag{3} \]

\[ u_{xx}(x, t) = \frac{u(x + h, t) - 2u(x, t) + u(x - h, t)}{h^2} + O(h^2). \tag{4} \]

Dropping the \(O(k^2)\) and \(O(h^2)\) terms and substituting into (1) gives the difference equation

\[ \frac{u_{i,j+1} - 2u_{i,j} + u_{i,j-1}}{k^2} = c^2\, \frac{u_{i+1,j} - 2u_{i,j} + u_{i-1,j}}{h^2}. \tag{5} \]

With the substitution \(r = ck/h\) it becomes \(u_{i,j+1} - 2u_{i,j} + u_{i,j-1} = r^2 (u_{i+1,j} - 2u_{i,j} + u_{i-1,j})\), which is solved for the value on the newest row:

ImportantExplicit formula for the wave equation

\[ u_{i,j+1} = (2 - 2r^2)\,u_{i,j} + r^2\,(u_{i+1,j} + u_{i-1,j}) - u_{i,j-1}, \qquad i = 2, 3, \ldots, n - 1, \tag{6} \]

where \(r = ck/h\).

Formula (6) computes row \(j + 1\) from four known values: three neighbouring values \(u_{i-1,j}\), \(u_{i,j}\), \(u_{i+1,j}\) in row \(j\) and the value \(u_{i,j-1}\) directly below in row \(j - 1\). This four-point pattern is the stencil of the method. Because it reaches back two rows, two starting rows are needed.

Starting Values

The first row is \(u_{i,1} = f(x_i) = f_i\). The second row, at \(t = k\), is not given, so it is built from Taylor’s formula in \(t\) about \((x_i, 0)\). To first order, \(u(x_i, k) = u(x_i, 0) + u_t(x_i, 0)\,k + O(k^2)\), and with \(g_i = g(x_i)\) this gives

\[ u_{i,2} = f_i + k\,g_i, \qquad i = 2, 3, \ldots, n - 1. \tag{7} \]

Errors in the second row are carried through the rest of the grid by formula (6), so a better second row is worth having. When \(f\) has a second derivative, the wave equation turns the unknown \(u_{tt}\) at \(t = 0\) into a known \(x\)-derivative of \(f\):

\[ u_{tt}(x_i, 0) = c^2 u_{xx}(x_i, 0) = c^2 f''(x_i) = c^2\, \frac{f_{i+1} - 2f_i + f_{i-1}}{h^2} + O(h^2). \]

Taylor’s formula of order 2, \(u(x, k) = u(x, 0) + u_t(x, 0)\,k + \tfrac12 u_{tt}(x, 0)\,k^2 + O(k^3)\), then gives

\[ u(x_i, k) = f_i + k g_i + \frac{c^2 k^2}{2h^2}\,(f_{i+1} - 2f_i + f_{i-1}) + O(h^2)\,O(k^2) + O(k^3), \]

and with \(r = ck/h\) this simplifies to the second-row formula that Mathews’ program uses:

ImportantSecond row

\[ u_{i,2} = (1 - r^2) f_i + k g_i + \frac{r^2}{2}\,(f_{i+1} + f_{i-1}), \qquad i = 2, 3, \ldots, n - 1. \tag{8} \]

Stability

Mathews calls the method stable if an error made at one stage of the calculation is eventually damped out, and states that stability of formula (6) requires \(r = ck/h \le 1\). The condition is a general result, and a Fourier analysis shows where it comes from; it also shows that for \(r \le 1\) errors are not damped but stay bounded. Since the boundary values are zero, look for solutions of (6) of the form \(u_{i,j} = \lambda^{j} \sin(p\pi x_i/a)\), one for each mode \(p = 1, 2, \ldots, n - 2\) that the grid can represent. Substituting into (6) and dividing by \(\lambda^{j-1}\sin(p\pi x_i/a)\) gives

\[ \lambda^2 - (2 - 4r^2 s_p)\,\lambda + 1 = 0, \qquad s_p = \sin^2\!\left(\frac{p\pi h}{2a}\right). \tag{9} \]

The two roots have product \(1\). If \(|2 - 4r^2 s_p| < 2\), that is \(r^2 s_p < 1\), they are complex conjugates of modulus \(1\), and the mode neither grows nor decays. If \(r^2 s_p = 1\) they coincide at \(\lambda = -1\) and the mode can grow, but only linearly. If \(r^2 s_p > 1\), they are real and negative, and one of them has modulus greater than \(1\): the mode grows geometrically and changes sign at every step. Since \(s_p < 1\) for every mode, \(r \le 1\) gives \(r^2 s_p < 1\), and all modes stay bounded. As \(h \to 0\) the largest \(s_p\) approaches \(1\), so \(r \le 1\) is the condition that works for every grid.

TipStability condition (general result)

The explicit formula (6) for the wave equation is stable when

\[ r = \frac{ck}{h} \le 1. \]

For \(r > 1\), on any grid fine enough that \(r^2 s_{n-2} > 1\), the highest modes the grid can carry grow without bound as the rows are computed.

The condition has a physical reading. The exact value \(u(x, t)\) depends on the initial data in \([x - ct,\ x + ct]\), while the value \(u_{i,j}\) computed by (6) can depend only on initial values in \([x_i - (j-1)h,\ x_i + (j-1)h]\), because each row reaches one grid point further to each side. The numerical interval contains the true one only when \(h/k \ge c\), which is \(r \le 1\) (the Courant–Friedrichs–Lewy condition). Implicit methods, which are more work to implement, have no stability restriction on \(r\).

WarningOn a coarse grid the threshold is slightly above 1

Only the modes \(p \le n - 2\) exist on a given grid, so the exact threshold there is \(r = 1/\sqrt{s_{n-2}}\), slightly above \(1\). For the grid of Examples 1 to 3 (\(n = 11\), \(h = 0.1\)) it is \(1/\sin(9\pi/20) \approx 1.0125\); only mode \(p = 9\) is unstable at \(r = 1.02\).

D’Alembert’s Solution and Exact Rows

The French mathematician Jean Le Rond d’Alembert (1717–1783) found that

\[ u(x, t) = F(x + ct) + G(x - ct) \tag{10} \]

solves the wave equation (1), as direct substitution shows: \(u_{tt} = c^2 F''(x + ct) + c^2 G''(x - ct) = c^2 u_{xx}\). The boundary conditions \(u(0, t) = u(a, t) = 0\) hold when \(F\) and \(G\) are odd and have period \(2a\): \(F(-z) = -F(z)\), \(F(z + 2a) = F(z)\), and likewise for \(G\). The solution with \(u(x, 0) = f(x)\) and \(u_t(x, 0) = 0\) is

\[ u(x, t) = \tfrac12 \bigl(\tilde f(x + ct) + \tilde f(x - ct)\bigr), \tag{11} \]

where \(\tilde f\) is the odd extension of \(f\) with period \(2a\). The initial shape splits into two halves that travel left and right at speed \(c\) and are reflected, upside down, at the fixed ends.

When \(r = 1\), that is \(k = h/c\), the grid lines line up with the characteristics \(x \pm ct = \text{const}\), and the method becomes exact.

TipTheorem — Two exact rows give an exact grid

Assume that the two rows \(u_{i,1} = u(x_i, 0)\) and \(u_{i,2} = u(x_i, k)\), \(i = 1, 2, \ldots, n\), are exact values of the solution of (1). If the step \(k = h/c\) is chosen, then \(r = 1\) and formula (6) becomes

\[ u_{i,j+1} = u_{i+1,j} + u_{i-1,j} - u_{i,j-1}, \tag{12} \]

and the values it produces throughout the grid are exact values of the solution (apart from computer rounding).

Proof. With \(ck = h\), \(x_i - ct_j = (i - 1)h - (j - 1)h = (i - j)h\) and \(x_i + ct_j = (i + j - 2)h\), so by (10) every exact grid value has the form \(u_{i,j} = F((i - j)h) + G((i + j - 2)h)\). Substituting this into the right side of (12),

\[ \begin{aligned} u_{i+1,j} + u_{i-1,j} - u_{i,j-1} &= F((i + 1 - j)h) + F((i - 1 - j)h) - F((i - j + 1)h) \\ &\quad + G((i + j - 1)h) + G((i + j - 3)h) - G((i + j - 3)h) \\ &= F((i - (j + 1))h) + G((i + (j + 1) - 2)h) = u_{i,j+1}. \qquad \blacksquare \end{aligned} \]

The theorem needs an exact second row, and formulas (7) and (8) generally do not give one. There is one common case where they do. When \(g = 0\) and \(r = 1\), formula (8) reduces to

\[ u_{i,2} = \frac{f_{i-1} + f_{i+1}}{2}, \qquad i = 2, 3, \ldots, n - 1, \tag{13} \]

and by (11) the exact value is \(u(x_i, k) = \tfrac12\bigl(\tilde f(x_i + h) + \tilde f(x_i - h)\bigr)\), which is the same thing, because \(ck = h\) and the points \(x_i \pm h\) are grid points in \([0, a]\), where \(\tilde f = f\). So with \(g = 0\) and \(r = 1\) the method reproduces the exact solution at every grid point. Examples 1 and 2 are of this kind.

Algorithm

Mathews’ program has two parts.

  1. Starting rows. Set \(h = a/(n - 1)\), \(k = b/(m - 1)\) and \(r = ck/h\). Fill row 1 with \(u_{i,1} = f(x_i)\) for \(i = 1, \ldots, n\), and fill row 2 by formula (8) for \(i = 2, \ldots, n - 1\). All other entries start at \(0\), so the end columns \(u_{1,j}\) and \(u_{n,j}\) stay \(0\) for \(j \ge 2\).
  2. Later rows. For \(j = 3, 4, \ldots, m\) and \(i = 2, \ldots, n - 1\), compute \[ u_{i,j} = (2 - 2r^2)\,u_{i,j-1} + r^2\,(u_{i+1,j-1} + u_{i-1,j-1}) - u_{i,j-2}. \]

The result is an \(n \times m\) array whose column \(j\) is the shape of the string at time \(t_j\). Mathews plots this array as a surface over the index grid (the axes are labelled \(x(i)\) and \(t(j)\) and carry the indices \(i = 1, \ldots, 11\) and \(j = 1, \ldots, 21\), not the values of \(x\) and \(t\)), seen from the viewpoint \((4, 2, 3)\) and coloured by height.

In all three examples below \(c = 2\) (so \(c^2 = 4\)), the string has length \(a = 1\), \(g(x) = 0\), and the grid has \(n = 11\) columns and \(m = 21\) rows. The examples differ in the initial position \(f\) and the time interval \([0, b]\).

What the exact second row is worth

The theorem depends on the second row being exact. If the first-order formula (7), \(u_{i,2} = f_i\), is used instead of (13) on the same grid, the second row is already off by up to \(0.2212\), and the error over the whole grid reaches \(0.3976\), since formula (6) carries it forward without damping it.

With \(r < 1\) the method is no longer exact, but it converges at second order. Running Example 1 with \(r = 0.5\) (so \(k = h/4\)) over \(0 \le t \le 1\), with the second row from (8):

\(h\) \(k\) max error over the grid ratio to the previous error
\(0.1\) \(0.025\) \(1.392 \times 10^{-1}\) —
\(0.05\) \(0.0125\) \(3.609 \times 10^{-2}\) \(3.857\)
\(0.025\) \(0.00625\) \(9.031 \times 10^{-3}\) \(3.996\)
\(0.0125\) \(0.003125\) \(2.257 \times 10^{-3}\) \(4.002\)

Halving \(h\) and \(k\) together divides the error by about \(4\), the behaviour expected from the \(O(h^2)\) and \(O(k^2)\) terms dropped in (3) and (4).

At \(t = 0.5\) the string has the shape \(u(x, 0.5) = -f(1 - x)\), the initial shape mirrored and inverted, with its lowest point \(-0.6\) at \(x = 0.4\); it then retraces its motion and returns to \(f\) at \(t = 1\).

The computed values agree with (11) at all \(11 \times 21\) grid points to within \(4.5 \times 10^{-16}\). For example, at \(x = 0.4\), \(t = 0.5\): \(\tfrac12(\tilde f(1.4) + \tilde f(-0.6)) = \tfrac12(-f(0.6) - f(0.6)) = -0.6\), the entry in the table. Mathews prints the full \(21\)-row table, and every entry agrees with the values computed here; the textbook’s Table 10.2 gives the same rows for \(0 \le t \le 0.5\).

Example 3 — the same string with \(r = 1.02\): instability

Mathews repeats Example 2 with the same \(f\), \(g = 0\) and \(c = 2\), but over the slightly longer rectangle \(R = \{(x, t) : 0 \le x \le 1,\ 0 \le t \le 1.02\}\), and asks the reader to notice the instability this produces, as predicted by the analysis above. The archive has lost the lines of the notebook that state his grid, and the plot of his result. Keeping Example 2’s grid, \(n = 11\) and \(m = 21\), the new interval gives

\[ h = 0.1, \qquad k = \frac{1.02}{20} = 0.051, \qquad r = \frac{2(0.051)}{0.1} = 1.02 > 1. \]

Steps. Row 1 is \(f\), row 2 comes from formula (8) with \(r^2 = 1.0404\), and rows 3 to 21 from formula (6) with \(2 - 2r^2 = -0.0808\). The second row is no longer exact (formula (13) no longer applies), but the larger problem is stability: by (9) the mode \(p = 9\), which on this grid is the sawtooth \(\sin(9\pi x_i) = (-1)^{i}\sin(\pi x_i)\), has \(r^2 s_9 > 1\) and the roots \(\lambda = -1.2762\) and \(\lambda = -0.7836\).
