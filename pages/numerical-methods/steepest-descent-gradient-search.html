Steepest Descent - Gradient Search

← Numerical Methods

Source inspiration: (Mathew 2000-2019).

Description

The gradient method, also called the method of steepest descent, looks for a local minimum of a function \(f(\mathbf{X})\) of \(n\) variables, \(\mathbf{X} = (x_1, \ldots, x_n)\), whose first partial derivatives can be evaluated. At the current point \(\mathbf{P}_k\) the gradient \(\nabla f(\mathbf{P}_k)\) points in the direction in which \(f\) increases fastest, so the unit vector opposite to it is the direction of steepest descent. The method searches along the line through \(\mathbf{P}_k\) in that direction for the lowest value of \(f\) and moves there:

\[ \mathbf{S}_k = -\frac{\nabla f(\mathbf{P}_k)}{\lVert \nabla f(\mathbf{P}_k) \rVert}, \qquad \mathbf{P}_{k+1} = \mathbf{P}_k + h_k\,\mathbf{S}_k, \qquad h_k \approx \operatorname*{arg\,min}_{\gamma \ge 0}\, f(\mathbf{P}_k + \gamma\,\mathbf{S}_k). \]

Each iteration needs only the gradient and a one-variable minimisation along a line. When that line minimisation is exact, \(f\) decreases at every step and each new search direction is perpendicular to the previous one, so the path to the minimum is a zigzag. In a long, narrow valley the zigzag steps are short and the method is slow. Mathews carries out the line search with a single quadratic interpolation per step (the quadratic interpolative search idea), and his examples work in two variables, \(\mathbf{P}_k = (x_k, y_k)\): a quadratic, Rosenbrock’s banana-shaped valley, a quartic with three local minima and a rational function. Every run below was recomputed with his line search and stopping rule in 60-digit arithmetic and agrees with a 120-digit run to more than 50 digits.

The Gradient and the Direction of Steepest Descent

NoteDefinition — Gradient

Let \(z = f(\mathbf{X})\) be a function of \(\mathbf{X} = (x_1, x_2, \ldots, x_n)\) such that \(\partial f(\mathbf{X})/\partial x_k\) exists for \(k = 1, 2, \ldots, n\). The gradient of \(f\) is the vector

\[ \nabla f(\mathbf{X}) = \left( \frac{\partial f(\mathbf{X})}{\partial x_1},\ \frac{\partial f(\mathbf{X})}{\partial x_2},\ \ldots,\ \frac{\partial f(\mathbf{X})}{\partial x_n} \right). \tag{1} \]

TipTheorem — Direction of steepest descent (general)

Let \(f\) be differentiable at \(\mathbf{P}\) with \(\nabla f(\mathbf{P}) \neq \mathbf{0}\). The rate of change of \(f\) at \(\mathbf{P}\) in the direction of a unit vector \(\mathbf{u}\) is \(\nabla f(\mathbf{P}) \cdot \mathbf{u}\). By the Cauchy–Schwarz inequality it lies between \(-\lVert \nabla f(\mathbf{P}) \rVert\) and \(\lVert \nabla f(\mathbf{P}) \rVert\), with the largest value for \(\mathbf{u} = \nabla f(\mathbf{P}) / \lVert \nabla f(\mathbf{P}) \rVert\) and the smallest for

\[ \mathbf{u} = -\frac{\nabla f(\mathbf{P})}{\lVert \nabla f(\mathbf{P}) \rVert}. \]

So locally \(f\) increases fastest along \(\nabla f\) and decreases fastest along \(-\nabla f\). The decrease is local only: a long step in the direction \(-\nabla f\) can overshoot, which is why the method looks for the best step length along the line.

Illustrations — two gradients

Mathews starts by finding the gradients of two functions that reappear in the examples.

For the quartic of Example 3,

\[ f(x, y) = 5x^2 + x^4 - 9x^2 y + 3y^2 + 2y^4 + \tfrac14 x, \qquad \nabla f(x, y) = \bigl(10x + 4x^3 - 18xy + \tfrac14,\ \ -9x^2 + 6y + 8y^3\bigr). \]

For the rational function of Example 4, the quotient rule gives

\[ f(x, y) = \frac{x - y}{x^2 + y^2 + 2}, \qquad \nabla f(x, y) = \left( \frac{-x^2 + 2xy + y^2 + 2}{(x^2 + y^2 + 2)^2},\ \ \frac{-x^2 - 2xy + y^2 - 2}{(x^2 + y^2 + 2)^2} \right), \]

and at the point \((-3, -2)\), where \(x^2 + y^2 + 2 = 15\),

\[ \nabla f(-3, -2) = \left( \frac{9}{225},\ -\frac{19}{225} \right) = \left( \frac{1}{25},\ -\frac{19}{225} \right) \approx (0.04,\ -0.0844444). \]

Verification: both gradients were checked symbolically against direct differentiation (the differences simplify to \(0\)), and the value at \((-3, -2)\) was computed in exact rational arithmetic.

The Gradient Method

Start at \(\mathbf{P}_0\) and search along the line through \(\mathbf{P}_0\) in the direction \(\mathbf{S}_0 = -\nabla f(\mathbf{P}_0)/\lVert \nabla f(\mathbf{P}_0) \rVert\). The point \(\mathbf{P}_1\) is where \(f\), restricted to the line \(\mathbf{X} = \mathbf{P}_0 + \gamma\,\mathbf{S}_0\), has a local minimum. Then compute \(\mathbf{S}_1\) from \(\nabla f(\mathbf{P}_1)\), search along the line through \(\mathbf{P}_1\), and so on.

ImportantOutline of the gradient method

Suppose \(\mathbf{P}_k\) has been found.

  1. Evaluate the gradient vector \(\nabla f(\mathbf{P}_k)\).
  2. Compute the search direction \(\mathbf{S}_k = -\nabla f(\mathbf{P}_k) / \lVert \nabla f(\mathbf{P}_k) \rVert\).
  3. Minimise the function of one variable \[\varphi_k(\gamma) = f(\mathbf{P}_k + \gamma\,\mathbf{S}_k) \tag{2}\] on an interval \([0, b]\), where \(b\) is large. This gives a value \(\gamma = h_k\) at which \(\varphi_k\) has a local minimum, so \(f(\mathbf{P}_k + h_k \mathbf{S}_k)\) is a minimum of \(f\) along the search line.
  4. Construct the next point \(\mathbf{P}_{k+1} = \mathbf{P}_k + h_k\,\mathbf{S}_k\).
  5. Termination test: are \(f(\mathbf{P}_k)\) and \(f(\mathbf{P}_{k+1})\) close enough, and is the distance \(\lVert \mathbf{P}_{k+1} - \mathbf{P}_k \rVert\) small enough? If not, repeat.
TipTheorem — Properties with an exact line search (general)

Let \(f\) be continuously differentiable and let each \(h_k > 0\) be an exact local minimiser of \(\varphi_k\) in (2), with \(\nabla f(\mathbf{P}_k) \neq \mathbf{0}\).

  1. Descent. \(\varphi_k'(0) = \nabla f(\mathbf{P}_k) \cdot \mathbf{S}_k = -\lVert \nabla f(\mathbf{P}_k) \rVert < 0\), so \(f\) decreases strictly: \(f(\mathbf{P}_0) > f(\mathbf{P}_1) > \cdots > f(\mathbf{P}_k) > \cdots\).
  2. Zigzag. \(\varphi_k'(h_k) = \nabla f(\mathbf{P}_{k+1}) \cdot \mathbf{S}_k = 0\), and \(\mathbf{S}_{k+1}\) is a negative multiple of \(\nabla f(\mathbf{P}_{k+1})\), so \(\mathbf{S}_{k+1} \cdot \mathbf{S}_k = 0\): consecutive search directions are perpendicular.
  3. Limit. Every limit point \(\mathbf{P}\) of the sequence \(\{\mathbf{P}_k\}\) satisfies \(\nabla f(\mathbf{P}) = \mathbf{0}\).

Mathews states that if \(\mathbf{P}_k \to \mathbf{P}\) then \(f(\mathbf{P})\) is a local minimum. That is what happens in every run on this page, but in general the theory guarantees only a stationary point. Because \(f\) decreases at every step, the limit cannot be a strict local maximum, but a saddle point can be reached from special starting points: for \(f(x, y) = x^2 - y^2\) from \((1, 0)\), the first exact line search lands on the saddle point \((0, 0)\), where the gradient is zero and the method stops. With an approximate line search such as Mathews’ single quadratic fit, properties 1 and 2 hold exactly only when \(\varphi_k\) is a quadratic, as in Example 1. In the other examples they hold approximately, and each case says how closely.

TipTheorem — Rate on a quadratic (general)

Let \(f(\mathbf{X}) = f^{*} + \tfrac12 (\mathbf{X} - \mathbf{X}^{*})\,\mathbf{A}\,(\mathbf{X} - \mathbf{X}^{*})^{T}\), where \(\mathbf{A}\) is symmetric positive definite with smallest and largest eigenvalues \(\lambda_{\min}\) and \(\lambda_{\max}\), and let \(\kappa = \lambda_{\max}/\lambda_{\min}\). With exact line searches the gradient method satisfies

\[ f(\mathbf{P}_{k+1}) - f^{*} \le \left( \frac{\kappa - 1}{\kappa + 1} \right)^{2} \bigl( f(\mathbf{P}_k) - f^{*} \bigr). \]

When \(\kappa\) is large, the level curves of \(f\) are long, thin ellipses and the factor is close to \(1\).

WarningSlow convergence

Convergence to a minimum can be slow. In Mathews’ words, the geometry of a minimum often makes \(h_k\) small, so the method returns to the line search (step 3) many times. In four of the six runs below (Examples 1, 2, 3(ii) and 3(iii)) Mathews’ program reaches its work limit before its tolerance.

Mathews’ Implementation

Mathews’ Mathematica program has two parts: a line search that takes one step along \(\mathbf{S}_k\), and an outer loop that repeats it.

Line search. It carries a trial step \(h\) from one iteration to the next (\(h = 1\) at the start of a run). With \(Y_0 = \varphi_k(0)\), \(Y_1 = \varphi_k(h)\) and \(Y_2 = \varphi_k(2h)\) it repeats, at most \(15\) times:

  • if \(Y_0 \le Y_1\), the step is too long: halve \(h\) (the old middle point becomes the new right point) and evaluate the new middle point;
  • otherwise, if \(Y_2 < Y_1\), \(\varphi_k\) is still falling at \(2h\): double \(h\) (the old right point becomes the middle point) and evaluate the new right point;
  • otherwise \(Y_1 < Y_0\) and \(Y_1 \le Y_2\), so the points \(0\), \(h\), \(2h\) bracket a minimum: stop.

The step is the vertex of the parabola through \((0, Y_0)\), \((h, Y_1)\), \((2h, Y_2)\),

\[ h_k = \frac{h\,(4Y_1 - 3Y_0 - Y_2)}{2\,(2Y_1 - Y_0 - Y_2)}, \tag{3} \]

and \(\mathbf{P}_{k+1} = \mathbf{P}_k + h_k \mathbf{S}_k\). This is one quadratic fit, not repeated: \(h_k\) is the exact minimiser of \(\varphi_k\) only when \(\varphi_k\) is itself a quadratic. The trial step for the next iteration is the smallest of \(h\), \(|h_k|\), \(|h_k - h|\) and \(|h_k - 2h|\).

Outer loop and stopping rule. The program keeps \(\mathrm{Err}\), the smallest nonzero difference \(|Y_i - f(\mathbf{P}_{k+1})|\) (\(i = 0, 1, 2\)) met so far in the run, starting from \(\mathrm{Err} = 1\). It stops as soon as both \(h \le \delta\) and \(\mathrm{Err} \le \varepsilon\), or when a work counter reaches \(60\); each iteration adds \(j + 1\) to the counter, where \(j\) is the number of passes through the bracketing loop. Mathews uses \(\delta = \varepsilon = 10^{-10}\) in Examples 1, 2, 3(i) and 4, and \(\delta = \varepsilon = 10^{-14}\) in Examples 3(ii) and 3(iii).

In the tables below \(h_k\) is the step taken from \(\mathbf{P}_k\); since \(\lVert \mathbf{S}_k \rVert = 1\) it is also the distance from \(\mathbf{P}_k\) to \(\mathbf{P}_{k+1}\). \(\mathbf{P}^{*}\) is the minimum the run approaches. Mathews’ own tables, computed in machine arithmetic, print \(12\) decimal places (in scientific notation for the smallest values). Each example says how far they agree with the recomputation. In every one of his tables the first line pairs \(\mathbf{P}_0\) with a function value left over from the previous computation (his program prints \(f(\mathbf{P}_0)\) before evaluating it), so the tables here give the correct \(f(\mathbf{P}_0)\).

Example 1 — A quadratic, \(f(x, y) = x^2 - 4x + y^2 - y - xy\), from \((0.99, 1.01)\)

Use the gradient method to find the minimum of

\[ f(x, y) = x^2 - 4x + y^2 - y - xy, \qquad \mathbf{P}_0 = (0.99,\ 1.01). \]

Step 0 (gradient and Hessian):

\[ \nabla f(x, y) = (2x - y - 4,\ \ 2y - x - 1), \qquad \mathbf{H} = \begin{pmatrix} 2 & -1 \\ -1 & 2 \end{pmatrix}. \]

The only stationary point is \((3, 2)\), and \(\mathbf{H}\) has eigenvalues \(1\) and \(3\), so it is positive definite and \((3, 2)\) is the global minimum, with \(f(3, 2) = -7\).

Step 1 (first search direction): \(f(\mathbf{P}_0) = -3.9697\) and

\[ \nabla f(\mathbf{P}_0) = (-3.03,\ 0.03), \quad \lVert \nabla f(\mathbf{P}_0) \rVert = \sqrt{9.1818} = 3.030149, \quad \mathbf{S}_0 = \frac{(3.03,\ -0.03)}{3.030149} = (0.999951,\ -0.009900505). \]

Step 2 (the function on the search line): because \(f\) is quadratic, so is \(\varphi_0\):

\[ \varphi_0(\gamma) = f(0.99 + 0.999951\,\gamma,\ \ 1.01 - 0.009900505\,\gamma) = -3.9697 - 3.030149\,\gamma + 1.009900\,\gamma^2 . \]

Step 3 (line search): with \(h = 1\), \(Y_0 = -3.9697\), \(Y_1 = \varphi_0(1) = -5.989948\) and \(Y_2 = \varphi_0(2) = -5.990397\). Since \(Y_2 < Y_1\), \(h\) doubles to \(2\), giving \(Y_1 = -5.990397\) and \(Y_2 = \varphi_0(4) = 0.068106\), which brackets the minimum. Formula (3) gives

\[ h_0 = \frac{2\,\bigl(4(-5.990397) - 3(-3.9697) - 0.068106\bigr)}{2\,\bigl(2(-5.990397) + 3.9697 - 0.068106\bigr)} = 1.500222 . \]

The parabola through three points of a quadratic is the quadratic itself, so this is the exact minimiser of \(\varphi_0\), \(h_0 = \lVert \nabla f(\mathbf{P}_0) \rVert / (\mathbf{S}_0 \mathbf{H} \mathbf{S}_0^{T}) = 3.030149 / 2.019800\).

Step 4 (new point):

\[ \mathbf{P}_1 = (0.99,\ 1.01) + 1.500222\,(0.999951,\ -0.009900505) = (2.490149,\ 0.9951470), \qquad f(\mathbf{P}_1) = -6.242648 . \]

In exact arithmetic \(\mathbf{P}_1 = (25656/10303,\ 10253/10303)\) and \(f(\mathbf{P}_1) = -64318/10303\). The next trial step is \(|h_0 - 2| = 0.4997780\).

Step 5 (second iteration): \(\nabla f(\mathbf{P}_1) = (-153/10303,\ -15453/10303) \approx (-0.01485004,\ -1.499854)\), so \(\mathbf{S}_1 = (0.009900505,\ 0.999951)\). This is \(\mathbf{S}_0\) turned through a right angle, as the zigzag property predicts. The line search doubles \(h\) once, to \(0.9995559\), and gives \(h_1 = 0.7574629\), so

\[ \mathbf{P}_2 = (2.497648,\ 1.752573), \qquad f(\mathbf{P}_2) = -6.810718 . \]

Step 6 (the full run): Mathews’ program continues until the work counter reaches \(64\), after \(16\) iterations. The tolerance test is never met.

Example 2 — Rosenbrock’s parabolic valley, \(f(x, y) = 100(y - x^2)^2 + (1 - x)^2\), from \((0.99, 1.01)\)

Use the gradient method to find the minimum of Rosenbrock’s function (circa 1960),

\[ f(x, y) = 100\,(y - x^2)^2 + (1 - x)^2, \qquad \mathbf{P}_0 = (0.99,\ 1.01). \]

Step 0 (gradient and minimum):

\[ \nabla f(x, y) = \bigl(-400x\,(y - x^2) - 2(1 - x),\ \ 200\,(y - x^2)\bigr). \]

The minimum is \(f(1, 1) = 0\), at the end of the curved valley floor \(y = x^2\). There

\[ \mathbf{H}(1, 1) = \begin{pmatrix} 802 & -400 \\ -400 & 200 \end{pmatrix} \]

has eigenvalues \(0.3993608\) and \(1001.601\), a ratio \(\kappa \approx 2508\): the valley is very narrow.

Step 1 (first iteration): \(f(\mathbf{P}_0) = 0.089501\), \(\nabla f(\mathbf{P}_0) = (-11.8604,\ 5.98)\) and \(\mathbf{S}_0 = (0.8929225,\ -0.4502105)\), almost straight across the valley. The trial step \(h = 1\) is far too long: \(\varphi_0(1) = 892.1648\). The line search halves \(h\) six times, to \(1/64 = 0.015625\), where \(Y_1 = \varphi_0(1/64) = 0.002469813\) lies below both \(Y_0 = 0.089501\) and \(Y_2 = \varphi_0(1/32) = 0.1619027\). Formula (3) then gives

\[ h_0 = 0.01333, \qquad \mathbf{P}_1 = (1.001903,\ 1.003999), \qquad f(\mathbf{P}_1) = 7.222046 \times 10^{-6}. \]

\(\varphi_0\) is not a quadratic, and its exact minimum is at \(\gamma = 0.01341122\), where \(\varphi_0 = 3.907525 \times 10^{-6}\). Because the step stops short of it, \(\mathbf{S}_1 = (0.8852766,\ -0.4650649)\) points almost the same way as \(\mathbf{S}_0\) (the two differ by \(0.96^\circ\)) instead of turning a right angle.

Step 2 (the full run): the counter reaches \(61\) after \(9\) iterations.

Example 3 — Three local minima, \(f(x, y) = 5x^2 + x^4 - 9x^2 y + 3y^2 + 2y^4 + \tfrac14 x\)

Mathews sets this as an exercise: graph

\[ f(x, y) = 5x^2 + x^4 - 9x^2 y + 3y^2 + 2y^4 + \tfrac14 x, \]

estimate the local minima from the graphs (the contour plot is the most useful), then go for each one with the gradient method.

Step 0 (the stationary points): \(\nabla f = \bigl(10x + 4x^3 - 18xy + \tfrac14,\ -9x^2 + 6y + 8y^3\bigr)\) has exactly five real zeros, classified by the eigenvalues of the Hessian:

Example 4 — \(f(x, y) = (x - y)/(x^2 + y^2 + 2)\) from \((-3, -2)\)

Use the gradient method to find the minimum of

\[ f(x, y) = \frac{x - y}{x^2 + y^2 + 2}, \qquad \mathbf{P}_0 = (-3,\ -2). \]

Step 0 (the minimum): \(\nabla f(-1, 1) = (0, 0)\), \(f(-1, 1) = -\tfrac12\) and \(\mathbf{H}(-1, 1) = \tfrac14 \mathbf{I}\). The minimum is round: near it the level curves are almost circles. The function is also symmetric about the line \(y = -x\), since \(f(-y, -x) = f(x, y)\).

Step 1 (first iteration): from the illustration above, \(\nabla f(\mathbf{P}_0) = (0.04,\ -0.0844444)\) and \(\lVert \nabla f(\mathbf{P}_0) \rVert = 0.09343909\), so

\[ \mathbf{S}_0 = (-0.4280863,\ 0.9037378), \qquad \varphi_0(\gamma) = \frac{-1 - 1.331824\,\gamma}{2 + (-3 - 0.4280863\,\gamma)^2 + (-2 + 0.9037378\,\gamma)^2}. \]

The line search starts with \(h = 1\): \(Y_0 = -0.06666667\), \(Y_1 = \varphi_0(1) = -0.1559377\) and \(Y_2 = \varphi_0(2) = -0.2166925\). It doubles \(h\) twice, to \(4\), where \(Y_1 = \varphi_0(4) = -0.2359675\) and \(Y_2 = \varphi_0(8) = -0.1650125\). Formula (3) gives

\[ h_0 = 4.818676, \qquad \mathbf{P}_1 = (-5.062809,\ 2.354820), \qquad f(\mathbf{P}_1) = -0.2235760 . \]

The exact minimum of \(\varphi_0\) is at \(\gamma = 3.292600\), where \(\varphi_0 = -0.2404550\): the parabola through \(\gamma = 0, 4, 8\) overshoots it. Mathews’ textbook works this same iteration (its Example 8.9), and there \(4.8186760\) is called the minimum of \(\varphi_0\). It is the single quadratic-interpolation estimate, not the minimum.

Step 2 (second iteration): \(\nabla f(\mathbf{P}_1) = (-0.03809377,\ 0.001596349)\) and \(\mathbf{S}_1 = (0.9991231,\ -0.04186903)\), at \(117.75^\circ\) to \(\mathbf{S}_0\). The trial step \(0.8186760\) is doubled twice, to \(3.274704\), and

\[ h_1 = 2.770828, \qquad \mathbf{P}_2 = (-2.294411,\ 2.238808), \qquad f(\mathbf{P}_2) = -0.3692574, \]

while the exact minimum of \(\varphi_1\) is at \(\gamma = 3.891620\). The textbook’s \(\mathbf{P}_1\), \(\mathbf{S}_1\), \(h_1\) and \(\mathbf{P}_2\) agree with these values.

Step 3 (the full run): the run ends after \(8\) iterations because the tolerances are met (the counter stands at \(47\)).

This run behaves differently from Examples 1 to 3. The first step lowers \(f\) but moves away from the minimum, from a distance of \(3.606\) to \(4.283\), and the first directions are far from perpendicular (\(117.75^\circ\) and \(40.86^\circ\)). From \(\mathbf{P}_2\) on, every search direction is within \(1.75^\circ\) of \((1, -1)/\sqrt2\), within \(0.18^\circ\) from \(\mathbf{P}_3\) on, and the iterates close in on the mirror line \(y = -x\) (\(x_3 + y_3 = -0.002002\), \(x_4 + y_4 = -1.117 \times 10^{-4}\)). Near the round minimum \(-\nabla f\) points almost straight at \((-1, 1)\), so there is no zigzag. Each step lands much closer than the last: the distances fall by factors \(0.31\), \(0.19\), \(0.049\), \(0.0026\), \(5.0 \times 10^{-6}\) and \(8.2 \times 10^{-10}\).

Mathews’ table agrees with rows \(1\) to \(7\) to within \(9.1 \times 10^{-13}\), but it has a ninth iteration and prints \((-0.999999998992,\ 0.999999998992)\) for both \(\mathbf{P}_8\) and \(\mathbf{P}_9\). Those points are \(1.4 \times 10^{-9}\) from \((-1, 1)\), farther than his \(\mathbf{P}_7\). That is rounding error: so close to the minimum, \(f\) differs from \(-\tfrac12\) by less than machine arithmetic can resolve, and the quadratic fit (3) divides one rounding error by another.

Example 5 — Drawing the iterations

Mathews’ last example returns to the quadratic of Example 1 with a version of the program that draws each step. On a contour plot of \(f\) over \([2.5, 3.05] \times [1.6, 2.15]\) it draws the level curve of \(f\) through \(\mathbf{P}_k\), the search line from \(\mathbf{P}_k\) in the direction \(\mathbf{S}_k\), and the three trial points \(\mathbf{P}_k\), \(\mathbf{P}_k + h\mathbf{S}_k\) and \(\mathbf{P}_k + 2h\mathbf{S}_k\), then marks the new point. This version also differs in detail from the program above: it starts with \(h = 0.2\), stops when the counter reaches \(20\), and takes \(h_k = h/3\) when the three trial values do not lie on an upward parabola. The starting point and the output of this example survive only in images that are missing from the archive, so the run cannot be reproduced. Its plotting window contains \((3, 2)\), the minimum of Example 1, whose run is tabulated in full above.
