Adams-Bashforth-Moulton Method

← Numerical Methods

Source inspiration: (Mathew 2000-2019).

Description

The Adams-Bashforth-Moulton (ABM) method is a predictor-corrector multistep scheme for the initial value problem \(y' = f(t,y)\), \(y(t_0) = y_0\), on a grid \(t_n = t_0 + nh\) in \([t_0, b]\). One-step methods such as Euler’s, Heun’s and Runge-Kutta step from the current point alone; ABM reuses the slopes \(f_k = f(t_k, y_k)\) at the four latest points. In the 4-step form, an explicit Adams-Bashforth predictor estimates \(y_{n+1}\) from this history, and an implicit Adams-Moulton corrector immediately refines it:

\[ p_{n+1} = y_n + \frac{h}{24}\bigl(55 f_n - 59 f_{n-1} + 37 f_{n-2} - 9 f_{n-3}\bigr), \]

\[ y_{n+1} = y_n + \frac{h}{24}\bigl(9 f(t_{n+1}, p_{n+1}) + 19 f_n - 5 f_{n-1} + f_{n-2}\bigr). \]

Both formulas integrate a cubic that interpolates the slopes over \([t_n, t_{n+1}]\): the predictor’s cubic passes through the four past slopes, the corrector’s through three past slopes and the predicted one. With the past slopes stored, a step needs only two new evaluations of \(f\), at \(p_{n+1}\) and at \(y_{n+1}\).

Mathews’ theorem assumes that \(f\) is continuous and satisfies a Lipschitz condition in \(y\), and the coefficients assume a fixed step \(h\). ABM is not self-starting: \(y_1\), \(y_2\), \(y_3\) must come from a one-step method accurate to \(O(h^4)\), usually fourth-order Runge-Kutta.

In general (Mathews’ precision theorem), if \(y \in C^5[t_0, b]\), the local truncation error is \(O(h^5)\) and the global error \(|y(t_n) - y_n|\) is \(O(h^4)\), so halving a small enough \(h\) cuts the error about 16-fold. Since predictor and corrector have equal order, their difference estimates the local error, \(y(t_{n+1}) - y_{n+1} \approx -\tfrac{19}{270}(y_{n+1} - p_{n+1})\) for slowly varying \(y^{(5)}\), and can guide the step size. Case 1 does not show the \(h^4\) rate: up to \(m = 90\) instability sets the \(y(5)\) error, which falls 190-fold from \(m = 70\) to \(m = 80\), against 1.7 for \(h^4\). For \(m \ge 100\) the error does not grow after the frames’ shading begins; the largest error is truncation error near \(t \approx 3.3\), and the damped tail cuts the \(y(5)\) error faster than \(h^4\).

The pair is only conditionally stable: on \(y' = \lambda y\) with real \(\lambda < 0\) it damps errors only while \(h|\lambda| \le 1.285\). In Case 1, \(y' = 1 - t\sqrt[3]{y}\), \(y(0) = 1\), the solution decays to \(y(5) = 0.0081199\), and \(\partial f/\partial y = -t/(3y^{2/3})\) reaches \(-41.3\) at \(t = 5\), so by a frozen-coefficient analysis \(h\,|\partial f/\partial y|\) passes \(1.285\) before \(t = 5\) in every frame. For \(m = 12\) to \(60\) the run leaves the reference in the tail, its largest error is between \(0.096\) and \(0.74\), and \(y(5)\) jumps between \(-0.363\) and \(0.632\). The end value alone can also mislead: at \(m = 12\), \(y(5)\) is off by \(0.013\), while the run is off by \(0.74\) at \(t \approx 4.17\).

Predictor-Corrector Methods sets out the general framework, Milne-Simpson’s Method is the other fourth-order predictor-corrector pair, the Runge-Kutta Method supplies the starting values, and Runge-Kutta-Fehlberg is a one-step alternative with an adaptive step.

The animation below repeats the step-refinement sweep of Mathews’ animation for legacy Example 11 of the module: \(y' = 1 - t\sqrt[3]{y}\), \(y(0)=1\), over \(0 \le t \le 5\). Each frame is a complete ABM4 run with \(m\) subintervals (\(h=5/m\), the first three steps by RK4), for the 21 values of Mathews’ animation, \(m = 12, 14, 16, 18, 20, 24, 28, 32, 36, 40, 44, 48, 52, 56, 60, 70, 80, 90, 100, 120, 150\), labelled with the computed \(y(5)\) and its error.

The thick gray curve is a high-accuracy reference trajectory computed with fixed-step RK4 at \(h=10^{-4}\), since no closed-form exact solution is used for this case.

Case 1 - ABM4 predictor-corrector step-refinement sweep, \(y' = 1 - t\sqrt[3]{y}\), \(y(0)=1\), \(m = 12\) to \(150\) subintervals

Behavior: The reference solution rises from \(y(0)=1\) to about \(1.4498\) near \(t=0.88\), then decays to \(y(5)=0.0081199\). For \(m=12\) through \(52\) the computed curve visibly breaks away from the reference in the tail (from \(t\approx3.2\) to \(4.7\), depending on \(m\)), and each of these runs goes below zero somewhere (then \(\sqrt[3]{y}\) is the real cube root), at \(m=48\) only to \(-0.0049\), too little to see. For \(m=56\) and \(60\) the run stays on the reference until about \(t=4.8\) and \(4.9\) and then rises above it, by up to \(0.11\) and \(0.096\). Across \(m=12\) to \(60\) the end value jumps between \(y(5)\approx-0.363\) (\(m=20\)) and \(0.632\) (\(m=16\)), and a small absolute end error can hide a much worse run: at \(m=12\), \(y(5)=0.0214\) is off by only \(0.013\) (an error 1.6 times the exact value, so \(y(5)\) is 2.6 times it), while the run is off by \(0.74\) at \(t\approx4.17\). From \(m=60\) on, the error in \(y(5)\) falls at every refinement: \(9.6\times10^{-2}\) at \(m=60\), \(2.1\times10^{-3}\) at \(m=70\) (26% of \(y(5)\), but too small to see in the frame), \(1.1\times10^{-5}\) at \(m=80\), \(4.5\times10^{-9}\) at \(m=100\) and \(1.4\times10^{-10}\) at \(m=150\).

A frozen-coefficient linear stability analysis shows where this can start, not how large it gets. \(\partial f/\partial y=-t/(3y^{2/3})\) reaches \(-41.3\) at \(t=5\), and this ABM4 predictor-corrector is stable on \(y'=\lambda y\) with real \(\lambda<0\) only while \(h|\lambda|\le1.285\). So for every \(m\le160\) (\(h>0.0311\)), which includes every frame here, \(h\,|\partial f/\partial y|\) exceeds \(1.285\) before \(t=5\) (the shaded region, from \(t\approx2.83\) at \(m=12\) to \(t\approx4.89\) at \(m=150\)), and past that point the linear analysis no longer guarantees that errors are damped. For \(m=12\) to \(60\) the error at the last step before the shaded region is between \(5.6\times10^{-5}\) and \(2.2\times10^{-3}\), and after it the error reaches \(0.096\) to \(0.74\); for \(m=100\), \(120\) and \(150\) it is below \(10^{-8}\) there, and the error at \(t=5\) is smaller still. So \(h=0.0311\) is a linear stability bound, not an accuracy threshold. The module’s worked solution of Example 11 uses \(n=50\), \(100\) and \(150\) steps: the \(n=100\) and \(150\) runs (frames \(m=100\) and \(150\) here) end at \(y(5)=0.0081199\), while the \(n=50\) run (\(h=0.1\)) falls to \(y_{48}\approx-0.0018\) at \(t=4.8\) and ends at \(y(5)\approx0.138\), about 17 times the exact value.
