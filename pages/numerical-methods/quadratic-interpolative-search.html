Quadratic Interpolative Search

← Numerical Methods

Source inspiration: (Mathew 2000-2019).

Description

Quadratic interpolative search finds the minimum of a unimodal function \(f\) on an interval \([a, b]\) by fitting a parabola through three function values and moving to the parabola’s lowest point. The version on this page is the one in Mathews’ module and Mathematica subroutine, which uses three equally spaced points \(p_0\), \(p_1 = p_0 + h\), \(p_2 = p_0 + 2h\). It starts from \(p_0 = a\) with \(h = (b - a)/2\) and steps to the right when \(f'(p_0) < 0\), to the left when \(f'(p_0) > 0\). It then halves \(h\) while \(f(p_0) \le f(p_1)\) and doubles it while \(f(p_2) < f(p_1)\), until the middle value is the lowest, \(f(p_0) > f(p_1) \le f(p_2)\). With \(y_i = f(p_i)\), the vertex of the interpolating quadratic is

\[ p_{\min} = p_0 + h_{\min}, \qquad h_{\min} = \frac{h\,(4y_1 - 3y_0 - y_2)}{2\,(2y_1 - y_0 - y_2)}. \]

The search restarts from \(p_0 = p_{\min}\), with \(h\) equal to the distance from \(p_{\min}\) to the nearest of the three old points. It stops when one of \(y_0, y_1, y_2\) agrees with \(f(p_{\min})\) to within a tolerance \(\varepsilon\).

The module also covers cubic interpolative search, which uses derivative values explicitly. It fits a cubic \(P\) to the values of \(f\) and \(f'\) at two points \(p_0\) and \(p_1 = p_0 + h\), and moves to the local minimum of the cubic, \(p_2 = p_0 + \gamma h\), where

\[ \gamma = \frac{-2h f'(p_0)}{(G - 3\alpha) + \sqrt{(G - 3\alpha)^2 - 12 h \alpha f'(p_0)}}, \qquad F = f(p_1) - f(p_0), \quad G = h\bigl(f'(p_1) - f'(p_0)\bigr), \quad \alpha = G - 2\bigl(F - h f'(p_0)\bigr). \]

Then \((p_0, p_1)\) is replaced by \((p_1, p_2)\) and the step repeats. The cubic search does not keep a bracket: in both of Mathews’ examples its first point \(p_1\) lies outside \([a, b]\). The examples below keep Mathews’ numbers. Examples 1 and 3 use the quadratic search and Examples 2 and 4 the cubic search. Examples 1 and 2 minimise the same function, and so do Examples 3 and 4.

Unimodal Functions and the Derivative Test

NoteDefinition — Unimodal function

The function \(f\) is unimodal on \(I = [a, b]\) if there is a unique number \(p \in I\) such that \(f\) is decreasing on \([a, p]\) and increasing on \([p, b]\).

Bracketing searches such as the golden ratio and Fibonacci searches need only this condition. The two methods on this page also use the derivative. Suppose \(f\) is unimodal on \([a, b]\) with minimum at \(p\), \(f'\) exists on \((a, b)\), and \(p_0 \in (a, b)\). If \(f'(p_0) < 0\) the minimum lies to the right of \(p_0\), and if \(f'(p_0) > 0\) it lies to the left.

Both of Mathews’ functions are unimodal on \([0, 1]\):

  • \(f(x) = x^2 - \sin x\) has \(f''(x) = 2 + \sin x \ge 2 > 0\) on \([0, 1]\), \(f'(0) = -1 < 0\) and \(f'(1) = 2 - \cos 1 = 1.4597 > 0\). The minimiser is the root of \(2x = \cos x\), \(p = 0.4501836113\), with \(f(p) = -0.2324655752\).
  • \(f(x) = \tfrac12 + x^5 - \tfrac45 x\) has \(f''(x) = 20x^3 > 0\) on \((0, 1]\), \(f'(0) = -0.8\) and \(f'(1) = 4.2\). The minimiser is exact: \(5p^4 = \tfrac45\) gives \(p = (4/25)^{1/4} = \sqrt{10}/5 = 0.6324555320\), with \(f(p) = 0.0952284595\).

Quadratic Interpolative Search

Bracketing the minimum

The first task is to find three test values

\[ p_0, \qquad p_1 = p_0 + h, \qquad p_2 = p_0 + 2h \tag{1} \]

such that

\[ f(p_0) > f(p_1) \qquad\text{and}\qquad f(p_1) < f(p_2). \tag{2} \]

Suppose \(f'(p_0) < 0\), so that \(p_0 < p\) and \(h\) is chosen positive. One pass of the bracketing loop does one of three things:

  • Case (i): if (2) holds, the bracket is found.
  • Case (ii): if \(f(p_0) > f(p_1)\) and \(f(p_1) > f(p_2)\), then \(p_2 < p\) and the points must reach farther right. Double the step: \(p_1 \leftarrow p_2\), \(h \leftarrow 2h\), \(p_2 \leftarrow p_0 + 2h\).
  • Case (iii): if \(f(p_0) \le f(p_1)\), the step has jumped over \(p\) and is too large. Halve the step: \(p_2 \leftarrow p_1\), \(h \leftarrow h/2\), \(p_1 \leftarrow p_0 + h\).

Each pass of cases (ii) and (iii) evaluates \(f\) at one new point. When \(f'(p_0) > 0\) the step \(h\) is negative and the same three cases apply. Mathews’ subroutine accepts the bracket when \(f(p_0) > f(p_1)\) and \(f(p_2) \ge f(p_1)\), so a tie between \(f(p_1)\) and \(f(p_2)\) also ends the loop. The loop also stops if \(|h|\) falls to a minimum step \(\delta\). Mathews’ text starts with \(h = 1\), or \(h = \tfrac12\) if \(a + 1 < b\) fails. His subroutine starts with \(h = (b - a)/2\), which for the interval \([0, 1]\) of both examples is the same \(h = \tfrac12\).

The vertex of the interpolating quadratic

With \(y_i = f(p_i)\) for \(i = 0, 1, 2\), the Lagrange polynomial through the three points (1) is

\[ Q(x) = y_0\,\frac{(x - p_1)(x - p_2)}{2h^2} - y_1\,\frac{(x - p_0)(x - p_2)}{h^2} + y_2\,\frac{(x - p_0)(x - p_1)}{2h^2}, \tag{3} \]

and its derivative is

\[ Q'(x) = y_0\,\frac{2x - p_1 - p_2}{2h^2} - y_1\,\frac{2x - p_0 - p_2}{h^2} + y_2\,\frac{2x - p_0 - p_1}{2h^2}. \tag{4} \]

Write the critical point as \(x = p_0 + h_{\min}\), set \(Q'(p_0 + h_{\min}) = 0\), multiply by \(2h^2\) and collect the terms in \(h_{\min}\):

\[ 0 = h_{\min}(2y_0 - 4y_1 + 2y_2) + y_0(2p_0 - p_1 - p_2) - y_1(4p_0 - 2p_0 - 2p_2) + y_2(2p_0 - p_0 - p_1). \]

With \(p_1 = p_0 + h\) and \(p_2 = p_0 + 2h\) the last three terms are \(-3hy_0 + 4hy_1 - hy_2\), so

\[ h_{\min} = \frac{h\,(4y_1 - 3y_0 - y_2)}{2\,(2y_1 - y_0 - y_2)}, \qquad p_{\min} = p_0 + h_{\min}. \tag{5} \]

Subtracting \(h\) gives the position of the vertex relative to the middle point:

\[ p_{\min} - p_1 = h_{\min} - h = \frac{h\,(y_0 - y_2)}{2\,(y_0 - 2y_1 + y_2)}. \tag{6} \]

TipProperty of the vertex step (general)

The second derivative of \(Q\) is \(Q'' = (y_0 - 2y_1 + y_2)/h^2\). If the triple is bracketed, \(y_0 > y_1\) and \(y_2 \ge y_1\), then \(Q'' > 0\), so \(p_{\min}\) is the minimum of \(Q\), and

\[ -\tfrac12 |h| < \operatorname{sign}(h)\,(p_{\min} - p_1) \le \tfrac12 |h|, \]

with equality only when \(y_2 = y_1\). So \(p_{\min}\) lies within half a step of \(p_1\), strictly between \(p_0\) and \(p_2\). To see this, put \(u = y_0 - y_1 > 0\) and \(v = y_2 - y_1 \ge 0\); then (6) reads \((p_{\min} - p_1)/h = (u - v)/\bigl(2(u + v)\bigr)\), and \(|u - v| < u + v\) unless \(v = 0\).

In the seven vertex steps of Examples 1 and 3, \(|p_{\min} - p_1|/|h|\) takes the values \(0.128\), \(0.105\), \(0.418\) and \(0.107\), \(0.270\), \(0.490\), \(0.165\), all below \(\tfrac12\).

WarningWhen the vertex formula fails (general)

The denominator \(2(2y_1 - y_0 - y_2)\) of (5) is zero when the three points are collinear, \(y_1 = (y_0 + y_2)/2\). If the triple is not bracketed, for instance because the bracketing loop stopped at \(|h| \le \delta\), then \(Q\) can be concave, and (5) then gives its maximum, or \(p_{\min}\) can lie far outside the triple. In Examples 1 and 3 every bracketing loop ends in case (i), so neither problem arises.

Restarting and stopping

Mathews notes that \(p_{\min}\) is a better approximation to \(p\) than \(p_0\), so the search replaces \(p_0\) by \(p_{\min}\) and repeats both processes with a new \(h\). His subroutine takes the new step to be the distance from \(p_{\min}\) to the nearest point of the old triple,

\[ h_{\text{new}} = \min\bigl\{\,|h_{\min}|,\ |h_{\min} - h|,\ |h_{\min} - 2h|\,\bigr\}, \tag{7} \]

and uses \(h_{\text{new}} = h_{\min}\) if this minimum is zero. The sign of \(f'(p_{\min})\) then sets the direction of the next step. (The subroutine evaluates (7) after replacing \(h\) by \(|h|\), so the three numbers are the distances to \(p_0\), \(p_1\), \(p_2\) only for a step to the right. Every outer step of Examples 1 and 3 goes to the right.)

The subroutine stops on function values, not on the distance to \(p\). After each vertex it computes \(e_i = |y_i - f(p_{\min})|\) for \(i = 0, 1, 2\). \(\mathrm{Err}\) is the smallest nonzero \(e_i\) found so far, starting from \(\mathrm{Err} = 1\), and the search stops when \(\mathrm{Err} \le \varepsilon\). It also stops after 50 outer steps, and each bracketing loop is limited to 50 passes.

Mathews writes that the method uses the derivative only implicitly, through (4), and makes no explicit use of \(f'\). His subroutine does evaluate \(f'(p_0)\) once per outer step, but uses only its sign, to choose the direction.

ImportantAlgorithm — Quadratic search for a minimum (Mathews’ subroutine)

Given \(f\) unimodal on \([a, b]\), a minimum step \(\delta\) and a tolerance \(\varepsilon\): set \(p_0 = a\), \(h = (b - a)/2\), \(\mathrm{Err} = 1\), \(k = 0\).

  1. If \(f'(p_0) > 0\), set \(h = -|h|\). Evaluate \(y_i = f(p_i)\) at the triple (1).
  2. While \(|h| > \delta\) and the triple is not bracketed: if \(y_0 \le y_1\), halve (case iii); otherwise, if \(y_2 < y_1\), double (case ii).
  3. Compute \(h_{\min}\) and \(p_{\min} = p_{3k+3}\) from (5), and \(f(p_{\min})\).
  4. Update \(\mathrm{Err}\) from the \(e_i\) and set the new \(h\) from (7).
  5. Set \(p_0 = p_{\min}\) and \(k \leftarrow k + 1\). Repeat from step 1 while \(\mathrm{Err} > \varepsilon\).

The tables label the points as Mathews does. The bracketing triple of outer step \(k\) is \(p_{3k}, p_{3k+1}, p_{3k+2}\), its vertex is \(p_{3k+3}\), and the trial points of the bracketing loop are \(q_{3k+2,j}\), \(j = 0, 1, \ldots\)

Example 1 — Minimise \(x^2 - \sin x\) on \([0, 1]\)

Find the minimum of

\[ f(x) = x^2 - \sin x \]

on \([0, 1]\) with the quadratic search. Mathews calls his subroutine with \(\delta = \varepsilon = 10^{-6}\).

Step 1 (first triple): \(p_0 = 0\) and \(f'(0) = -1 < 0\), so \(h = (1 - 0)/2 = 0.5\) is positive. The triple is

\[ p_0 = 0,\quad p_1 = 0.5,\quad p_2 = 1, \qquad y_0 = 0,\quad y_1 = -0.2294255386,\quad y_2 = 0.1585290152 . \]

Since \(y_0 > y_1 < y_2\), this triple is already bracketed (case i).

Step 2 (first vertex): from (5),

\[ h_{\min} = \frac{0.5\,(4y_1 - 3y_0 - y_2)}{2\,(2y_1 - y_0 - y_2)} = \frac{0.5\,(-1.0762311696)}{-1.2347601848} = 0.4358057471, \]

so \(p_3 = 0.4358057471\) and \(f(p_3) = -0.2322143232\).

Step 3 (restart): the distances from \(p_3\) to the old points are \(0.4358057471\), \(0.0641942529\) and \(0.5641942529\), so by (7) the new step is \(h = 0.0641942529\), the distance to \(p_1 = 0.5\). The differences \(e_i\) are \(0.232\), \(2.79 \times 10^{-3}\) and \(0.391\), so \(\mathrm{Err} = 2.79 \times 10^{-3} > 10^{-6}\) and the search continues. Since \(f'(p_3) = -0.0349 < 0\), the step stays positive.

Step 4 (second bracket): the new triple is \(0.4358057471\), \(0.5\), \(0.5641942529\), with values \(-0.2322143232\), \(-0.2294255386\), \(-0.2164199625\). Since \(y_0 \le y_1\), halve: \(q_{5,0} = 0.4679028735\), with \(f = -0.2320824604\), is still above \(y_0\), so halve again: \(q_{5,1} = 0.4518543103\), with \(f = -0.2324621759\). Now \(y_0 > y_1\) and \(y_2 = f(0.4679028735) > y_1\), so the bracket is \((0.4358057471, 0.4518543103, 0.4679028735)\) with \(h = 0.0160485632\).

Step 5 (second vertex): (5) gives \(h_{\min} = 0.0143625245\), so \(p_6 = 0.4501682715\) and \(f(p_6) = -0.232465574872\). The new step is \(h = 0.0016860388\), the distance to \(0.4518543103\), and \(\mathrm{Err} = 3.40 \times 10^{-6}\).

Step 6 (third bracket and vertex): six halvings bring the step down to \(h = 2.63444 \times 10^{-5}\), and the vertex is \(p_9 = 0.4501836113\). Now \(\mathrm{Err} = 1.47 \times 10^{-10} \le 10^{-6}\), and the search stops.

Example 3 — Minimise \(\tfrac12 + x^5 - \tfrac45 x\) on \([0, 1]\)

Find the minimum of

\[ f(x) = \frac12 + x^5 - \frac45\,x \]

on \([0, 1]\) with the quadratic search, again with \(\delta = \varepsilon = 10^{-6}\). This is the example of Mathews’ quadratic-search animation. His solution prints the points in the order of the table below and interleaves the printed lines with graphs of \(f\) that mark the current points. This example uses all three cases of the bracketing loop.

Step 1 (first triple and vertex): \(f'(0) = -0.8 < 0\) and \(h = 0.5\). The triple \(0, 0.5, 1\) has values \(0.5\), \(0.13125\), \(0.7\), so it is bracketed. Here \(4y_1 - 3y_0 - y_2 = -1.675\) and \(2(2y_1 - y_0 - y_2) = -1.875\), so

\[ h_{\min} = \frac{0.5\,(-1.675)}{-1.875} = 0.4466666667 = \tfrac{67}{150}, \qquad p_3 = 0.4466666667, \qquad f(p_3) = 0.1604460919. \]

The new step is the distance to \(0.5\), \(h = 0.0533333333\), and \(\mathrm{Err} = 2.92 \times 10^{-2}\).

Step 2 (doubling, case ii): the triple \(0.4466666667\), \(0.5\), \(0.5533333333\) has values \(0.1604460919\), \(0.13125\), \(0.1092054735\), which decrease, so double: \(q_{5,0} = p_0 + 2(0.1066666667) = 0.66\), with \(f = 0.0972332576\), is lower again, so double once more: \(q_{5,1} = 0.8733333333\), with \(f = 0.3093759954\). The bracket is \((0.4466666667, 0.66, 0.8733333333)\) with \(h = 0.2133333333\). Its vertex is \(p_6 = 0.6023078449\), with \(f(p_6) = 0.0974207564\). This value is higher than \(f(0.66) = 0.0972332576\), and \(p_6\) is farther from \(p\) (\(0.0302\)) than \(0.66\) is (\(0.0275\)). The vertex is not always the best point found so far. The new step is \(h = 0.0576921551\), the distance to \(0.66\), and \(\mathrm{Err} = 1.87 \times 10^{-4}\).

Step 3 (bracketed at once): the triple \(0.6023078449\), \(0.66\), \(0.7176921551\) is bracketed without halving or doubling, and its vertex is \(p_9 = 0.6317169944\). None of its \(e_i\) is below \(1.87 \times 10^{-4}\), so \(\mathrm{Err}\) does not change.

Cubic Interpolative Search

The starting step

Assume \(f\) is unimodal and differentiable on \([a, b]\), with minimum at \(p\), and let \(p_0 = a\). Any reasonable step \(h\) can start the iteration. Mathews estimates one from the mean value theorem, \(f(a + h) - f(a) = h f'(c)\) for some \(c\) between \(a\) and \(a + h\). If \(a + h\) were just to the right of the minimum, the average slope \(f'(c)\) might be about \(\tfrac12 f'(a)\). Since the position of \(a + h\) is unknown, he takes \(f(a + h) \approx f(b)\) and obtains

\[ h_0 = \frac{2\bigl(f(b) - f(a)\bigr)}{f'(a)}, \qquad p_1 = p_0 + h_0. \tag{8} \]

When \(f'(a) < 0\), this \(h_0\) is positive only if \(f(b) < f(a)\). In both of Mathews’ examples \(f(b) > f(a)\), so \(h_0 < 0\) and \(p_1\) lies to the left of \(a\), outside the interval.

The interpolating cubic

Let \(h = p_1 - p_0\). The cubic \(P\) is written about the abscissa \(p_2\) of its minimum:

\[ P(x) = \frac{\alpha}{h^3}(x - p_2)^3 + \frac{\beta}{h^2}(x - p_2)^2 + f(p_2), \qquad P'(x) = \frac{3\alpha}{h^3}(x - p_2)^2 + \frac{2\beta}{h^2}(x - p_2). \tag{9} \]

It must satisfy \(P(p_0) = f(p_0)\), \(P(p_1) = f(p_1)\), \(P'(p_0) = f'(p_0)\) and \(P'(p_1) = f'(p_1)\). (The powers of \(h\) in the denominators make the following algebra simpler.) Put

\[ p_2 = p_0 + \gamma h, \tag{10} \]

so that \(p_1 - p_2 = (1 - \gamma)h\) and \(p_0 - p_2 = -\gamma h\). Substituting into (9) gives three equations:

\[ \begin{aligned} F &= f(p_1) - f(p_0) = \alpha(3\gamma^2 - 3\gamma + 1) + \beta(1 - 2\gamma), \\ G &= h\bigl(f'(p_1) - f'(p_0)\bigr) = 3\alpha(1 - 2\gamma) + 2\beta, \\ h f'(p_0) &= 3\alpha\gamma^2 - 2\beta\gamma. \end{aligned} \tag{11} \]

The book section linked from Mathews’ module gives the middle equation as \(G = f'(p_1) - f'(p_0)\), without the factor \(h\). The module and the subroutine include the factor, and it is needed. The combination \(G - 2(F - h f'(p_0))\) cancels both \(\beta\) and every \(\gamma\):

\[ \alpha = G - 2\bigl(F - h f'(p_0)\bigr). \tag{12} \]

Multiplying the second equation of (11) by \(\gamma\) and adding the third eliminates \(\beta\):

\[ 3\alpha\gamma^2 + (G - 3\alpha)\gamma + h f'(p_0) = 0. \tag{13} \]

The quadratic formula, with the numerator rationalised, gives the root Mathews uses:

\[ \gamma = \frac{-2h f'(p_0)}{(G - 3\alpha) + \sqrt{(G - 3\alpha)^2 - 12 h \alpha f'(p_0)}}. \tag{14} \]

TipWhich root (general)

From (9), \(P''(p_2) = 2\beta/h^2\), so \(p_2\) is a local minimum of \(P\) when \(\beta > 0\). Each critical point of the cubic through the four conditions gives a representation (9) about that point, so the two roots of (13) are the cubic’s two critical points. Form (14) is the root that stays finite as \(\alpha \to 0\). In that limit \(P\) is a quadratic and \(\gamma = -h f'(p_0)/G\), so

\[ p_2 = p_0 - f'(p_0)\,\frac{p_1 - p_0}{f'(p_1) - f'(p_0)}, \]

the secant step for \(f'(x) = 0\). If the discriminant in (14) is negative, the cubic has no critical point and the step is undefined.

In every step of Examples 2 and 4 the discriminant is positive and \(\beta > 0\), so (14) picks the local minimum of the cubic.

To continue, set \(h = p_2 - p_1\) and replace \(p_0, p_1\) by \(p_1, p_2\) in (11)–(14). The method does not keep a bracket, so a stopping rule is harder to choose. Mathews suggests \(|f'(p_k)| < \varepsilon\), since \(f'(p) = 0\). His subroutine simply runs a fixed number of steps.

ImportantAlgorithm — Cubic search for a minimum (Mathews’ subroutine)

Given \(f\) unimodal and differentiable on \([a, b]\) and a number of steps \(m_{\max}\): set \(p_0 = a\), \(h_0 = 2(f(b) - f(a))/f'(a)\), \(p_1 = p_0 + h_0\). For \(k = 0, 1, \ldots, m_{\max} - 1\):

\[ \begin{aligned} F &= f(p_{k+1}) - f(p_k), \qquad G = h_k\bigl(f'(p_{k+1}) - f'(p_k)\bigr), \qquad \alpha = G - 2\bigl(F - h_k f'(p_k)\bigr), \\ \gamma &= \frac{-2h_k f'(p_k)}{(G - 3\alpha) + \sqrt{(G - 3\alpha)^2 - 12 h_k \alpha f'(p_k)}}, \qquad p_{k+2} = p_k + \gamma h_k, \qquad h_{k+1} = p_{k+2} - p_{k+1}. \end{aligned} \]

Mathews’ algorithm statement lists \(p_1 = b\) among the starting values. In his subroutine \(b\) enters only through \(f(b)\) in \(h_0\), and the iteration starts from \(p_1 = p_0 + h_0\).

Comparing the Two Searches

Examples 1 and 2 minimise the same function, so the methods can be compared directly.

Method (on \(x^2 - \sin x\)) Information used Steps Error of the result
Quadratic search (Example 1) 20 calls of \(f\), sign of \(f'\) at 3 points 3 vertex steps \(2.0 \times 10^{-11}\)
Cubic search (Example 2) \(f\) and \(f'\) at the iterates \(p_3\) after 2 cubic steps, \(p_4\) after 3 \(3.5 \times 10^{-7}\), then \(1.1 \times 10^{-15}\)
Secant method on \(f'\) \(f'\) only \(p_6\) after 5 secant steps \(1.1 \times 10^{-13}\)

To see the rate of convergence without the limit of double precision, the three iterations were repeated in 400-digit arithmetic. The ratio \(\log e_{k+1} / \log e_k\) of successive errors measures the order:

  • Cubic search: the ratios settle near \(2\). The last ratios before the 400-digit limit are \(2.10\), \(1.98\), \(2.02\) in Example 2 and \(2.09\), \(1.95\), \(2.02\) in Example 4. This is consistent with the order \(2\) of cubic interpolation using function and derivative values (a general result).
  • Secant method on \(f'\): the ratios fall to \(1.62\), the golden ratio \((1 + \sqrt5)/2 \approx 1.618\) that is the general order of the secant method.
  • Mathews’ quadratic search: each outer step roughly squares the error. The ratios are \(2.61\), \(2.22\), \(2.11\), \(2.05\), \(2.02\), \(2.01\) in Example 1 and \(2.08\), \(2.06\), \(2.00\), \(2.02\), \(2.00\), \(2.00\), \(2.00\), \(2.00\) in Example 3. But the bracketing loops of the successive outer steps need more and more halvings or doublings: \(2, 6, 19, 34, 76, 156\) in Example 1 and \(2, 0, 5, 8, 13, 39, 82, 164\) in Example 3. In the last three steps of each run that is \(1.4\) to \(1.7\) passes, each costing one evaluation of \(f\), per decimal digit gained. Counted per function evaluation, the quadratic search therefore converges far more slowly than the squaring per step suggests.

This variant is not the textbook successive parabolic interpolation, which keeps the three most recent points, unequally spaced, and needs no bracketing loop.

Implementation Notes

  • Quadratic search, direction. The subroutine evaluates \(f'(p_0)\) once per outer step and uses only its sign. A version without derivatives must choose the direction from function values instead.
  • Quadratic search, step rule. Rule (7) gives the distance from \(p_{\min}\) to the nearest old point only when \(h > 0\), because the subroutine replaces \(h\) by \(|h|\) first. Every outer step in Examples 1 and 3 has \(f'(p_0) < 0\) and therefore \(h > 0\).
  • Quadratic search, bracketing. Check that the triple really is bracketed before using (5). The loop can also end because \(|h| \le \delta\), and the vertex of an unbracketed or collinear triple is meaningless or undefined.
  • Quadratic search, stopping. \(\mathrm{Err}\) compares function values, which agree to about the square of the distance to \(p\) (Example 3: \(8.1 \times 10^{-13}\) in \(f\) against \(5.7 \times 10^{-7}\) in \(x\)). A tolerance \(\varepsilon\) on \(f\) therefore corresponds to a distance of roughly \(\sqrt{2\varepsilon / f''(p)}\) (general).
  • Cubic search, starting step. Formula (8) needs \(f'(a) \ne 0\), and with \(f(b) > f(a)\) it sends \(p_1\) outside \([a, b]\) (both examples). The method does not keep a bracket, and \(p_1\) can land where \(f\) is not convex, as in Example 4.
  • Cubic search, stopping. Use a test such as \(|f'(p_k)| < \varepsilon\) rather than a fixed number of steps. Once the iterates agree to rounding, \(F\), \(G\) and \(\alpha\) are pure rounding noise. Continued in double precision, both examples eventually reach \(0/0\) in (14): Example 2 at \(p_9\), after \(p_7 = p_8\) exactly, and Example 4 also at \(p_9\), where \(f'(p_7) = 0\) exactly. Mathews’ runs stop before this.
  • Unimodality. Neither method can tell a local minimum from the global one. If \(f\) has several minima in \([a, b]\), the result depends on the start.
